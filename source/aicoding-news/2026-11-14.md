[**双11直播间爆改AI秀场，罗永浩上手TRAE，秒变AI Coding的大众嘴替**](https://mp.weixin.qq.com/s/yxuH5rb2ldStl9bqdgbA3g)
双十一期间，AI 编程工具 **TRAE 以 9.9 元首月**登陆罗永浩直播间，现场演示三件事：几分钟生成调研报告（**不到 4 分钟**出一版纯文本报告，老罗当场挑刺迭代）、把 **5 万多字**的行业资料爆改成「演讲者版 + 自助阅读版」**两套**发布会级 PPT、凭手绘草图搓出一个语音输入法。文中给的规模数据：截至今年 6 月 **TRAE 全球注册用户超 1000 万、月活 160 万**，不少用户每周近 5 天在用；平台上**超 40% 的 PR 由 AI Agent 发起**，非专业人群的开源贡献在快速增长。作者的判断是：聊天问答类增长见顶，紧贴业务场景的代码生成与应用搭建是跑得最快的赛道。

[**基于本体的AI数据研发落地：淘宝行业经营分析实战**](https://mp.weixin.qq.com/s/rtav5KBF29LUcfX_2lUPUw)
一个经营分析需求往往要串起**数十甚至上百张表**，同名字段在不同场景含义不同，指标口径还随业务迭代变化；更麻烦的是大量业务规则**从没写进文档**，只存在于历史生产代码和资深研发的经验里。大模型写 SQL 因此常犯三类错：**选错表、用错字段、口径不对**——都能跑通、都不报错，常规测试拦不住。解法是引入**本体**：从生产代码中自动抽取隐性业务规则，做成 AI 可读、**可追溯到代码位置**的结构化知识，为 AI SQL Coding 提供精确输入。这是两位作者继《从 LLM 到 Ontology》之后在**淘宝行业经营分析**场景的落地篇；全文**未给量化指标**。

[**AI 10分钟写完代码，你2小时还在验？用验收Agent补上最后一公里**](https://mp.weixin.qq.com/s/k2LwwM4-u0OnPKvQqwlAWw)
AI 把写代码压到 10 分钟，**验收**反而成了新瓶颈——静态 Review 看不出 AI 生成的代码到底能不能用。做法：在 OPT 需求交付小队里加一个**后端验收 Agent**，核心工具 **api-acceptance** 在代码生成后**真实调用接口**，用接口返回、业务状态、日志、数据库**多层证据逐层验证**，流程拆成五个阶段。关键设计是把异常分成**硬阻塞**（不越过人机确认与环境前提）和**软失败**（发布失败、spec 缺失、日志暂不可用时仍继续做变更分析、场景生成、静态 Review 和风险标注）。首个落地业务已运行 **160+ 次**、覆盖 **30+ 个需求**、**80+ 个入口接口**、**800+ 个 Gherkin 场景**，发现 **20+ 条问题**并触发打回；单需求人工验收从约 **2 小时降到 20 分钟**（**-80%**）。

[**如何管理你的 Coding Agent？来自 Claude的一些实践**](https://mp.weixin.qq.com/s/gRMVLzSa3UUByDQJpxg_Bg)
使用编程智能体本质上是在做管理，最能发挥其价值的工程师往往已掌握管理能力。文章借鉴优秀工程管理者实践，提出与智能体协作的核心习惯：提供测试、构建等验证机制让其自行确认结果，交代目标、约束与成功标准等背景，让纠正积累为持久规则，默认交由智能体判断只强制不可妥协项，先明确计划再实现，尽早纠偏及时重启，委派任务但保留判断，设计好无人值守流程，扩大验证能力减少注意力依赖，并决定哪些事不做。不必先有管理头衔，但需学会通过支持他人取得成果的方式管理智能体。

## Agent基建

[**HyperAgent：openJiuwen对未来Agent架构的思考和实践**](https://mp.weixin.qq.com/s/ckokbxFq_uN5Ol_mPTWWvQ)
openJiuwen 社区判断：**Agent 正从“回答一个问题”走向“承担一份工作”**。它兼具**软件程序与智能主体**的二元属性（“数字智能生物”），架构要从偏重复杂任务深度执行的 **DeepAgent** 演进为 **HyperAgent**，八项特征是：**主动性**（目标/事件驱动，不等指令）、**永续性**（从 Sessionful 到 Sessionless，会话结束不中断）、**成长性**（SI → RSI → CoRSI）、**协作性**、**确定性**、**扩展性**、**开放性**、**经济性**。支撑这套形态的是分层设计的开源 **AgentOS**（把开发、运行、协作与演进连起来）；落地侧已在 **WorkSwarm** 推进蜂群协作与永续智能体。9 月发布架构，上周公开落地进展。

[**压测AI Agent 治理与评测调优实践**](https://mp.weixin.qq.com/s/7e9NZZGUJa3titSHleOtXg)
压测智能分析 Agent 上线后的治理闭环。方法：用 **Langfuse** 记录每次执行链路、还原问题现场，结合用户反馈判断错在**证据采集、工具调用、规则校验还是模型推理**；把高频问题固化成**固定场景回测集**，用**五档评分**打分，再按低分案例定位改进点。效果（001→007 两轮迭代）：**解决率 61.67% → 96.15%**，**平均延迟 175 秒 → 113 秒**，**单 Trace 成本 $0.5868 → $0.1980**；中间并非单调，**006 比 005 更快更省，但评分从 92.31% 回落到 83.33%**，说明质量与开销要一起看。Dubbo 专项评测由约 **50% 提升到 90%**，是整体改善的主要来源。

[**AI从Working、Coding到Oncall：腾讯视频如何让知识流动起来？**](https://mp.weixin.qq.com/s/aOV53imdYpJ8Sle24yBoUQ)
核心观点：**知识是组织型 AI 的土壤**——个人用 AI 提效不等于组织产出增长，卡点在于知识没有沉淀、没有流动。文中给出 **L0–L5 的 AI 应用成熟度模型**（L0 纯人工 → L1 工具渗透 → L2 流程嵌入 → L3 Agent 协作 → L4 高度自治 → L5 完全自治），并判断当下多数场景在 **L2 末期、L3 初期**，而 L2→L3 是分水岭：之前人驱动、AI 辅助，之后 AI 承接、人确认。方法论上把知识分四类管理（**环境、决策、业务、事实**），按“个人知识 → 团队知识 → 平台知识”演进。落地成绩很实：自助取数 AI 化 **90%**、从 3–5 天缩到分钟级；AI Working 工作台产运渗透 **>80%**；数据任务 Oncall **90%+** 由 Agent 跟进；埋点测试提效约 **70%**；Coding 侧需求渗透约 **40%**、活跃研发 **60%**，全链路提效 **17%–50%**，直播三端一码从预估 **1023 人天降到 140 人天**、两个月交付 12 万行代码。

[**一文拆解DSH Super-agent双层架构：如何做到后台跑任务、前台继续接活**](https://mp.weixin.qq.com/s/VMf36Wn27Iief5ydZkr3NQ)
拆 DeepSeek Harness（DSH）的 **Super-agent 双层架构**：**Router 层**管全局协调、维护上下文、做调度决策，**Worker 层**跑高并发执行，等于把“会话管理与上下文同步”从人手上移到系统层，做到后台跑任务、前台继续接活。文中给了三组机制与一组数字：**事件路由 / 订阅直通**（去掉直通后 Router 决策次数 +30%，读缓存 token 从 2323 万涨到 3177 万、约 +37%，说明直通在省钱）；**Router 批处理**把单个决策的推理时间从 6.4 秒压到 1.6 秒，靠攒批扛突发洪峰；另有 **异步 ReAct Loop** 与**投机执行**，让 Worker 不必等串行结果。整体是“人只定目标与验收，其余交给系统”。

[**记忆即智能：重构对话式AI Agent认知基座的四层渐进式记忆与自进化系统**](https://mp.weixin.qq.com/s/SvkRy9ipKEUbiLGbEPi08w)
对话式 AI 的共同病：没有记忆，换个渠道、隔个会话就重新认识你。文章用一套**四层渐进式记忆**从原始对话流逐层提炼成认知：**L0 数据底座**（只记录不加工）、**L1 感知层**（只观察不决策，抽每条消息的意图、情绪、回溯信号、行为完成度）、**L2 决策层**（唯一调度者，拿阶段状态机 + 策略库 + 规则库决定“该走哪条路”）、**L3 画像层**（长期记忆，用户维度六个特征：价格敏感度、信任度、操作熟练度、偏好时段、忙碌标签、回复风格）。节奏也是分层的：L0 实时落库 → L1 每条消息毫秒级 → L2 每条消息实时调度 → L3 24 小时定时 + 实时微调。关键设计原则是**每层只做一件事、决策权只给一层**，配合画像演化与策略效果闭环，做到“越用越懂你”。

[**构建稳定的 AI Agent：Harness 工程的核心机制与实践思考**](https://mp.weixin.qq.com/s/4fp0WcVZqSPW8exB0VxpIg)
一句话立论：**Agent = 模型 + Harness，模型负责聪明，Harness 负责稳**。Harness 原意是马具——缰绳、马鞍、护具，让模型“指哪打哪”。作者用团队 Agent 做 text2SQL 与流量分析时的翻车（上下文爆炸、超时、幻觉、权限乱）说明：光调提示词救不了，得管边界、调度和上下文。四个抓手：**约束动作空间**（skill/MCP/权限/重试熔断）、**管理 I/O 与上下文**（数仓分层降维：ODS/DWD 数 T 级 → DWS 百兆 → 按小时分区到几兆；1k+ API 按风险分级，高风险全量、中低风险 TopN 或抽样）、**调度交给确定性系统**（cron 会重复、漏跑、超时，改事件触发）、**状态与记忆持久化**（记忆当资产 + git 管提示词与配置）。落地细节很实：每个操作最多重试 2 次；查询改为导出一次快照、本地聚合；逻辑固化成脚本。效果是 Agent Loop 明显缩短，token 总量虽增但多在缓存读写，**缓存价只有普通输入价的 1/10**。

[**从进化到泛化，RSI 四大前沿框架如何实现 Agent 自动调优**](https://mp.weixin.qq.com/s/hGwPYgkcPARx1kTsDtXjHg)
梳理 Google 2025 年 10 月集中发的四篇 RSI（递归自我改进）论文，主线是 **从“改子模块”走向“系统级自我调优”**。四篇分工：**Harness²**（10/9）解决**没有金标答案时怎么自进化**——冻结模型参数，只改 Harness 里的 System Prompt、Skill、Tool、Memory、Sub-agent，按六步流程迭代；**Evo²**（同日）不只改模型，还把“**改进过程本身**”变成可迁移的经验；**RRSI**（9 月首版、10 月更新）用**七步正则化进化**防止自我改进“过拟合”；**OO-Harness**（10/20）走**面向对象**的 Harness 组织方式。结论：RSI 已从局部进化迈向系统级泛化。

[**抢跑DeepSeek！硅谷华人把下一代Agent Harness造出来了！？**](https://mp.weixin.qq.com/s/w7JDM7qMsfYFvt27NH_wIw)
DeepSeek 提出 Super-agent 架构设想，硅谷华人团队 **AFK AI** 早在半年前就把类似结构落进产品 **Comma** 并开源（前身是 Bridge）。出发点很具体：**普通人的注意力只能同时跟进 3–5 个活跃 Session**，人成了 AI 的瓶颈。架构是**单 Router + 多 Worker**——主 Agent 统筹任务、调度多个**各带独立上下文**的 Worker，做到连续记忆、高效并行、主动推进、持久在线，人只负责顶层决策；理念叫“**一个团队，一个对话**”。

## 行业应用

[**创造一个能读懂生命的 AI**](https://mp.weixin.qq.com/s/ZkvG5NxqaM9tJc1TbNZfcg)
SimpleX 的出发点是一个寓言：**如果代码失传，人类就再也读不懂自己写的东西**——所以生命也该有“可读的代码”。两位创始人 2019 年就判断，分子、蛋白质、基因和文字一样是**离散符号**，可以让同一个模型既读人的语言、也读生命的语言。产品 **Tetra-1** 把自然语言与蛋白质结构放进同一推理系统：用户用自然语言提问，模型给出推理依据和分子结构，目标从“看见蛋白质”升级为**能推测、能提猜想**。转折点是 2024 年 9 月 o1 出现，团队 2025 年果断转向推理模型。测试案例很硬：糖尿病靶点 **PTP1B** 的**隐藏变构口袋**（2004 年才被发现、位于催化位点约 **2 纳米**外、多数时候是关着的）。
