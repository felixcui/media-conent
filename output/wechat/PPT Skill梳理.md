# 5 个值得收藏的 PPT Skill

> 写在前面：PPT 这件事，AI 已经从「能不能生成」走到了「能不能直接讲清楚」。本文梳理了 5 个当前最受关注的开源 PPT Skill，覆盖网页演示、配图生成、多平台封面、原生可编辑 PPTX 等完整链路，帮你找到适合自己的那一套。

---

## 一、为什么要用 PPT Skill？

过去一年，AI 做 PPT 经历了两个阶段：

- **1.0 阶段**：比拼「能不能生成」。输入一句话，吐出一套模板化幻灯片，但常常内容水、排版土、设计感弱，后续返工比从头做还累。
- **2.0 阶段**：比拼「能不能用于商业级表达」。Agent 先理解需求、再规划内容、再匹配视觉、最后输出可修改或可演示的成果。

Skill 的价值就在于，它把这套完整流程写进了 Agent 的「菜谱」：告诉 AI 在什么场景下、按什么步骤、用什么工具、完成什么任务。用户只需点菜，AI 就能按标准稳定交付。

> 一句话理解 Skill：它不是替代你，而是替代你身上那些重复、冗长、易错的「做 PPT 任务」。

## 三、逐个介绍

### 1. Frontend Slides：让 AI 用前端能力做漂亮幻灯片

**项目地址**：https://github.com/zarazhangrui/frontend-slides

**一句话定位**：Create beautiful slides on the web using a coding agent's frontend skills。

Frontend Slides 的核心思路是：既然 Agent 已经会写前端代码，那就让它直接生成网页版幻灯片。它既可以从零生成 HTML 演示，也能把现有 PPT 转换成网页幻灯片重新设计。

#### 主要功能

- **从零生成 HTML 演示**：根据主题、内容、图片和演讲目标，生成完整的 16:9 网页幻灯片。
- **PPT 转网页**：提取 `.pptx` 中的文本、图片、备注，重新生成网页版。
- **视觉预览选风格**：不要求用户用设计术语描述，而是先生成多个视觉预览供选择。
- **内置丰富风格库**：深色、浅色、专业、复古、赛博、终端、纸本文艺等；还有来自 `beautiful-html-templates` 的 34 套大胆模板。
- **分享与导出**：可部署到 Vercel 生成在线链接，也可用 Playwright 导出 PDF。

#### 项目特点

- 低依赖：输出单个 HTML 文件，内联 CSS/JS，不需要 npm 或构建工具。
- 非设计师友好：用视觉预览降低选择门槛。
- 避免模板化审美：强调更有辨识度的风格。
- 结果可长期保存、可直接修改。

#### 适合谁

创业公司 pitch deck、产品发布、教学课件、内部汇报、把旧 PPT 转成网页版本、需要在线分享 URL 的演示。

### 2. HTML PPT Skill：零构建的网页幻灯片工具包

**项目地址**：https://github.com/lewislulu/html-ppt-skill

**一句话定位**：一个面向 AI Agent 的演示文稿生成技能包，用来快速制作专业级 HTML 幻灯片。

HTML PPT Skill 是纯前端静态方案，不依赖传统 PPT 软件，也不需要构建流程。打开 HTML 就能演示、截图、排练。

#### 主要功能

- **36 套主题**：minimal-white、editorial-serif、cyberpunk-neon、xiaohongshu-white、corporate-clean、academic-paper、pitch-deck-vc 等。
- **15 套完整 Deck 模板**：小红书杂志风、蓝图架构图风、终端赛博朋克风、Pitch Deck、产品发布、技术分享、周报、课程模块等。
- **31 种单页版式**：封面、目录、章节页、双栏/三栏、KPI 网格、表格、代码、Diff、终端、时间线、路线图、思维导图、对比、甘特图、图片墙、柱状图、折线图、饼图、雷达图、架构图、CTA、致谢页等。
- **47 种动画效果**：CSS 动画（淡入、上浮、缩放、打字机、霓虹、路径绘制、3D 翻页）+ Canvas FX 动画（粒子爆炸、礼花、星空、矩阵雨、知识图谱、神经网络、数据流、冲击波）。
- **演讲者模式**：按 `S` 打开演讲者窗口，含当前页/下一页预览、演讲稿、计时器，双窗口同步。

#### 项目特点

- 零构建：无需打包编译，直接打开 HTML 即可运行。
- 设计系统驱动：主题、字体、颜色、阴影、圆角由统一 CSS token 控制。
- 中英文友好：内置面向中文和英文的字体方案。
- 适合 Agent 自动生成：根据自然语言指令生成结构化、美观的 HTML 幻灯片。

#### 适合谁

技术分享、产品发布、创业融资 Pitch Deck、周报/月报、课程课件、小红书图文内容、架构方案说明、数据报告、AI Agent 自动生成演示文稿。

### 3. Guizang PPT Skill：把十年设计经验压进 Agent

**项目地址**：https://github.com/op7418/guizang-ppt-skill

**一句话定位**：面向 Claude Code、Codex、Cursor 等本地 Agent 的 PPT 生成 Skill，核心目标是让 Agent 生成可直接打开、演示、截图、排练的单文件 HTML 演示文稿。

Guizang PPT Skill 是 2026 年最受关注的 PPT Skill 之一，由设计师歸藏开源。它的特点不是「模板多」，而是「设计规则硬」——把瑞士国际主义和电子杂志风的设计纪律写进 Skill，让 AI 严格执行。

#### 主要功能

- **生成 HTML 横向翻页 PPT**：支持键盘、滚轮、触屏、底部圆点、ESC 索引视图。
- **两套内置视觉系统**：
  - **Style A 电子杂志风**：偏叙事、观点表达、个人分享，适合演讲、沙龙、内容发布。
  - **Style B 瑞士国际主义风**：偏结构化、理性、网格化表达，适合产品分析、商业汇报、AI 产品发布。
- **PPT 配图生成**：在 Codex 环境下配合 GPT-Image 2.0 / GPT-M 2.0，生成人文纪实照片、信息图、流程图、对比图、系统关系图、UI 情景图、数据图表等。
- **多平台封面生成**：公众号 21:9 头图、公众号 1:1 分享卡、小红书 3:4 封面、视频号 16:9 横版封面。
- **演讲者模式**：当前页/下一页预览、16:9 等比显示、演讲备注、每页计划时长、计时排练、自动翻页、宫格选页、激光笔、圈选标注、黑屏/白屏、冻结观众屏。
- **低性能静态模式**：按 `B` 关闭 WebGL / canvas 动画，降低演示时性能压力。

#### 项目特点

- 面向 Agent 工作流：把设计规范、模板、版式、主题、校验脚本整理成结构化文件。
- HTML 更适合 AI 修改：文本文件可直接编辑、验证和迭代。
- 设计限制较强：主题色必须从预设中选择、瑞士风必须使用固定版式、图片必须放进指定槽位，以提高生成稳定性。
- 质量校验机制：Node.js 脚本检查版式违规、图片槽位、标题留白、演讲备注完整性等。
- 单文件交付：方便本地打开、现场演示、截图、录屏、全屏播放。

#### 适合谁

线下演讲、行业内部分享、私享会、AI 产品发布、Demo Day、个人风格强烈的观点表达、产品分析、方法论分享、文章转演讲稿、社交媒体封面生成。

### 4. PPT Master：让 AI 生成真正可编辑的 PPT

**项目地址**：https://github.com/hugohe3/ppt-master

**一句话定位**：让 AI 从文档、网页、主题或现有 PPT 模板中生成真正可编辑的 PowerPoint 文件。

PPT Master 和其他 Skill 最大的不同：它输出的是原生 `.pptx`，不是 HTML 截图。目标是尽量调用 PowerPoint 的原生能力——形状、图表、表格、母版、动画、旁白、公式。

#### 主要功能

- **从资料自动生成 PPT**：支持 PDF、DOCX、网页、图片、文本、主题提纲、现有 `.pptx` 模板。
- **生成原生 PowerPoint 对象**：原生形状、连接线、可编辑文本、图片填充、数据驱动图表、数据表格、幻灯片母版/版式、可编辑公式（OMML）。
- **模板复用**：保留原有设计风格，填充新文本、更新表格/图表数据，结果仍可编辑。
- **动画、转场、旁白、视频化**：支持幻灯片转场、进入/强调/路径/退出动画、演讲者备注、从备注生成音频旁白、进一步生成视频。
- **图片生成与搜索**：可调用 `gpt-image-2`、`gemini-3.1-flash-image`，或搜索 Openverse、Wikimedia Commons、Pexels、Pixabay。

#### 项目特点

- 开源免费，MIT License。
- 数据主要在本地处理，适合对资料隐私敏感的场景。
- 不绑定单一平台/模型：可在 Claude Code、Cursor、Windsurf、Copilot、Cline、Codex CLI、Gemini CLI、Kimi Code 等运行。
- 强调「AI 先理解内容，再设计页面」，不是简单套模板。
- README 明确提醒：它是工具，不是许愿池；生成后通常仍需人工润色。

#### 适合谁

商业汇报、学术/研究传播、企业模板填充、内容营销/知识分享、自动化办公、需要交付 PPTX 的正式流程。

### 5. PPT Design Prompt：把品牌设计资料转成演示图片 Prompt

**项目地址**：https://github.com/Russell-cell/PPT-Design-Prompt

**一句话定位**：把品牌类的 `DESIGN.md` 资料转换成更适合 PPT、Keynote、PDF deck、视觉文章等场景的「演示图片生成提示词/设计指南」。

这个项目不是完整 PPT 生成器，而是解决一个更上游的问题：**如何让 AI 图像模型生成的配图，风格与品牌保持一致。**

#### 主要功能

- 将品牌设计说明中的网页/UI/品牌视觉规范，改写成面向幻灯片图片生成的 `DESIGN.md`。
- 输出到 `ppt-image/<brand>/DESIGN.md`。
- 提供 Python CLI，可本地批量转换。
- 生成转换清单 `conversion_manifest.json`。
- 支持品牌目录文件，便于追踪哪些品牌已转换。
- 提供不依赖第三方数据的最小示例。

#### 项目特点

- 面向演示图像，不是网页界面。
- 来源可追溯：改编自 VoltAgent 的 `awesome-design-md` 资料集合。
- 本地优先、批量转换、MIT License。

#### 适合谁

使用 AI 图像模型生成 PPT 封面/信息图/背景、为 Keynote/PowerPoint/PDF deck 统一视觉风格、将品牌视觉规范转成可执行图像提示词、构建设计 Agent 的品牌风格知识库。

## 四、5 个 Skill 怎么选？

| 你的需求 | 推荐 Skill |
| --- | --- |
| 想做网页版 PPT，要在线分享、可预览、风格多 | **Frontend Slides** |
| 想快速生成 HTML 演示，需要完整模板和动画库 | **HTML PPT Skill** |

## 五、写在最后

AI PPT 的竞争已经从「谁生成得快」升级到「谁能把表达这件事做完整」。

一条越来越清晰的路径是：

1. **意图洞察**：先把人话翻译清楚；
2. **内容规划**：联网搜索、搭骨架、生成可编辑大纲；
3. **视觉设计**：版式跟着内容长，而不是内容往模板里填；
4. **质量保障**：文字溢出、对齐、层级、图片填充自动检查；
5. **演讲闭环**：写稿、排练、模拟答辩、生成数字人讲解视频。

而 Skill 的作用，就是把这套流程变成 Agent 的「标准动作」。

对于创作者和职场人来说，真正重要的不是让 AI 替代你做 PPT，而是让 AI 替代你做 PPT 里那些重复、低价值的部分——你把时间省下来，放在内容本身和现场表达上。
