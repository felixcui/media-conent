# 昨晚听到一个非常精辟的 Personal Agent 判断。

**作者**: 阿颖

**来源**: https://mp.weixin.qq.com/s/e7ygV_ek4CA_GfWZ0GA7WA

---

## 摘要

文章借张小珺采访蚂蚁灵光负责人蔡伟的播客，提出Personal Agent的终局是重构服务业而非仅作为效率工具：它沿着ChatGPT解决信息、Coding Agent改变软件生产的路径，进入营养师、维修等专业服务场景，结合对用户的长期了解提供个性化、长周期服务，而移动互联网十余年积累的线上服务入口为其奠定基础。

张小珺采访蚂蚁灵光负责人蔡伟的这期播客，给了我不少启发。昨晚本来下班路上开车听了一小会，没想到根本停不下来，到了家，我索性留出来一个半小时，倍速听完了。

**这是小珺今年最精彩的一期播客了。**

![文章图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/iagroyM7YaBm4q5OxxHJUIO64MNKYBOuYQq1rcdRI1E1v5rqCz93F2JSicYZkEUb7BZMHmpq5zcouW8icWqGvTbxrDl83P2aAHFJPYAsj3vIq4/640?wx_fmt=jpeg&from=appmsg)

蔡伟是蚂蚁灵光的负责人，灵光在半年之前就已经在做 Personal Agent。我本来觉得应该没有多少增量的思考了，毕竟之前我听过很多 Muse 团队的分享。

**但出乎意料的是，蔡伟提供了一个我从未听过的视角，让我对 Personal Agent 有了新的理解。**

Personal Agent 火了之后，我一直在用。但说实话，到目前为止，我大部分重要的工作任务，还是交给 Codex 这些偏生产力的通用 Agent 来处理。

现在对我最有价值的 Personal Agent 使用场景，是让它帮我盯一些长周期的任务。比如关注竞品某个产品的迭代节奏，有重要变化的时候及时提醒我。

这样的场景确实很好用。

**但问题也来了，就像我同事说的：这件事情必须交给 Personal Agent 来做吗？** ChatGPT 不是也有定时任务吗？

我让它每天早上六点钟跑一次，检查竞品有没有更新，不也能做到吗？

我没办法清晰的回答同事这个困惑。直到听完今天这期播客。

******#01******

**Personal Agent 的终局是服务业**

因为 Personal Agent 现在还处于非常早期的阶段，很多能力都没有完全展现出来。

所以，我们很容易拿自己已经熟悉的 ChatGPT、Claude Code、OpenClaw 这些产品来做比较。

比如，Personal Agent 有主动性，ChatGPT 也可以定时执行任务。Personal Agent 有长期记忆，ChatGPT 也有。比来比去，确实很难找到清晰的边界。

**如果我们只是把 Personal Agent 当成通用 Agent 再加上主动性、长期记忆、个性化这些能力，那就大错特错了。**

沿着通用 Agent 的思路往前递进，Personal Agent 只是一个更好的个人效率工具，能帮我们节省时间，减少重复劳动。

**蔡伟的思考逻辑是，Personal Agent 会彻底重构整个服务业。** 看这张图就比较好理解。

最早的 ChatGPT，主要帮我们解决获取信息的问题。比如以前我们需要通过搜索引擎查找资料，现在可以直接让 AI 整理出答案。

后来，Claude Code 这样的 Coding Agent 出现，模型开始具备完成复杂任务的能力，能帮我们 Coding、制作 PPT、分析数据等。它改变了软件生产和使用的方式。

前面的两波产品，分别对应的是信息行业和软件行业。 **而 Personal Agent 对应的是服务业。**

大家可以想想，我们日常生活中有很多问题，都需要别人提供专业服务来解决。

想减肥，可能会请一个营养师。家里的空调坏了，需要找维修师傅。

这些事情都需要不同的人来提供服务。 **但如果 Personal Agent 足够了解我们，确实已经可以承担其中一部分工作了。**

比如营养师这个场景。今天的大模型已经掌握了大量营养学知识，结合我的身体状况、饮食习惯、运动记录、长期的健康目标，它就可以像私人营养师一样，给出个性化的建议。

而对于修空调这样的线下服务，虽然 AI 暂时没办法亲自上门维修，但它可以寻找维修师傅、比较报价、预约时间，甚至跟进整个维修过程。

****也就是说，随着模型能力不断提高，AI 能够提供的服务，正在从回答问题、完成任务，逐渐走向长期为一个人提供服务。****

其实这里还有一个非常重要的背景，就是移动互联网发展了十几年，已经帮 Personal Agent 打下了很好的基础。

我们可以回忆一下，十几年前，想打车、订酒店、买火车票，很多时候还得通过电话，或者跑到线下去办理。

反正我一直记得 2012 年春节前，我在寒风中，去立水桥附近的一个火车票代理点排队买票的场景。当时觉得北漂特苦。

**现在，很多服务都可以在线上完成，或者即使不能完成，至少也能在网上找到这些服务的入口。** 这是移动互联网带来的变化。沧海桑田般。

不过，虽然方便了很多，但我们仍然需要自己去搜索、比较、选择，还要处理各种预约和沟通。比如，我每次出去吃饭，就特别烦选餐厅、打电话订餐厅。

有时候还得反复确认时间、人数，甚至临时调整预约。

Personal Agent 也许可以直接干这些事。

比如家里的空调坏了，我准备换一台新的。

现在电商平台上什么空调都能买到，可是，真要买的时候，挺麻烦的。光是品牌就有一大堆，每个品牌下面还有不同的型号，价格、功能、能耗都不一样。

**为了买一台合适的空调，我可能得花好几个小时去研究。**

如果 Personal Agent 足够了解我，知道我的预算、品牌偏好，以及家里的实际情况，它就可以帮我筛选产品，比较不同商家的价格和服务，甚至在我确认之后，直接帮我下单。

******#02******

**服务业的供给侧改革**

**这也是播客里提到的服务业的供给侧改革。**

一方面，AI 本身开始具备提供服务的能力。

随着模型能力提高，它可以给用户提供越来越多的服务。

**而且 AI 的边际服务成本非常低，这意味着很多原本只有花钱请专业人士才能享受到的个性化服务，有机会变得非常便宜，甚至人人都能用上。**

相当于创造了大量新的服务供给。

另一方面，Personal Agent 还可以把已有的服务重新组织起来。

移动互联网已经把大量线下服务搬到了线上，但它们仍然分散在不同的平台上。每个平台提供的都是自己擅长的服务，至于怎么选择、怎么组合，基本上还是用户自己操心。

**但 Personal Agent 可以从用户的需求出发，决定需要哪些服务，再去调用对应的平台和商家。**

拿旅游来说，我真正的需求其实就是开开心心地出去玩几天。至于住哪家酒店、怎么安排行程、去哪里吃饭，这些都是为了完成这个目标需要解决的问题。

如果 Personal Agent 能够把这些事情全部协调好，实际上它就已经在提供一种更完整的旅游服务了。

所以，你会发现，酒店、餐厅、航空公司这些服务商并没有消失，但它们提供服务的方式，以及用户获得服务的方式，都可能发生变化。

**原本分散在不同平台上的供给，可以被 AI 根据每个人的实际需求，重新组合成一套完整的服务。**

![](https://mmbiz.qpic.cn/mmbiz_png/iagroyM7YaBmvCQMpbt58m7AOlJC3vibhCjlEPfGMuIlcJg8icwvdnUia6ImUV6qP0DpHzzicbyic4IBzfxbr1FLHmR6riavZsEBNibxViauKW8OICh8/640?wx_fmt=png&from=appmsg)

**这才是我觉得最有意思的地方。**

****Personal Agent 的价值，远远不只是帮我们少操作几个 App，它可以改变服务的生产和组织方式。**** 从这个角度来看，Personal Agent 确实有机会成为服务业的全新入口。

******#03******

**和移动互联网的区别**

前面聊了这么多供给侧改革、供需关系，听起来都是很大的词。

不过仔细想下，不只是 Personal Agent，Chatbot、Coding Agent，也都在不同程度上改变原有行业的供需关系。

就拿最近这一轮 Coding Agent 来讲。虽然之前行业里经常有人说，AI 会催生更多的软件需求，未来反而需要更多程序员。

但我说实话，这都是些冠冕堂皇的话。目前至少没看到这种变化。

我认识不少互联网公司的老板，从现在我拿到的反馈看，几乎所有公司对于工程师的需求都是在减少的。 **因为 Coding Agent 让软件的开发效率高了很多倍。**

大规模堆人搞软件开发的时候过去了。

AI 改变了软件这个行业的供需关系。

Chatbot 也是一样。 **它已经改变了知识和信息的供给方式。**

这点我每次出去旅游，感受都特别明显。以前遇到不熟悉的地方或者历史知识，可能要在搜索引擎上找半天资料。现在直接问 Chatbot，几秒钟就能得到比较完整的解释。

获取信息的成本已经比以前低太多了。

我们经常把这一轮 AI 浪潮和移动互联网做类比，其实两者有个很重要的区别。

![](https://mmbiz.qpic.cn/mmbiz_jpg/iagroyM7YaBkFulhlibTy1yvMbPBibY7R6JYgiaAe29iamicR9RxwlZoR4U58zLYUNytp6gXCQEUT11C3jpbcCENhlRHKF8slGemwcaqEdYIuj5aU/640?wx_fmt=jpeg&from=appmsg)

移动互联网那一轮，最重要的变化是智能手机创造了大量新的使用场景。

比如手机有了定位能力，我们可以随时随地使用各种线上服务，这才催生出了打车、外卖等一系列新的商业机会。

所以，移动互联网更多改变的是人们使用服务的场景和方式。但这一轮 AI，它开始直接改变很多服务的生产方式。

**说到这里，我想起扎克伯格之前聊 Muse 时的一个愿景，希望未来每个人都能拥有一个真正了解自己、能够长期帮自己处理事情的个人助理。**

你想想，我们生活中有多少事情，如果有个靠谱的助理能帮忙处理，那肯定会省心很多。

但为什么现在绝大多数普通人都没有助理呢？

因为成本太高了。毕竟真人的时间和精力有限，雇佣一个私人助理，负担不起。

**但假设未来 AI 能够承担管家相当一部分工作，一个月只需要花 20 块钱，却能帮我们创造 200 块钱，甚至 2000 块钱的价值。**

那毫无疑问，肯定会有很多人用。

****过去只有少数人消费得起的服务，随着 AI 能力提高、成本下降，普通人也能享受到。**** 这才是 Personal Agent 最有想象空间的地方。

******#04******

**Personal Agent 的市场格局**

理解了 Personal Agent 可能会带来整个服务业的变革，我们就能明白为什么蚂蚁这么重视这个机会。

因为蚂蚁的杀手级应用支付宝，本身就连接了大量生活服务。从支付到各种线下商家，再到整个生活服务生态，这些都是过去十几年积累下来的。

**所以，蚂蚁本身就在漩涡的中心。**

![](https://mmbiz.qpic.cn/sz_mmbiz_png/iagroyM7YaBkiajukIotiaISaTPaPicibHTtEqeffXpQPqTYtubwIfNQGHdv0xg9NNRibXfoQ3oyN5aoEXW6wicFx8myibjWQPRiazyEF0Picadd4xo4w/640?wx_fmt=png&from=appmsg)

**蔡伟在播客里也总结了，做好 Personal Agent 有三个核心要素：智能、供给和安全。**

智能很好理解，就是模型和 Harness 本身要足够聪明和可靠，能够理解用户的需求，并且有很强的长程任务执行能力。

**其实 Personal Agent 之所以在这个时间点火起来，也是因为过去一年模型的长程任务能力取得了很大进步。**

供给也就是我们前面聊的，Agent 要能够连接现实世界中的各种服务。

比如打车、订酒店、预约维修这些事情，如果没有背后的服务供给，Agent 再聪明也没办法真正帮用户完成任务。所以，服务生态越丰富，Agent 能够帮我们解决的问题就越多。

再就是安全。

这点其实我们之前已经聊过很多了。 **因为 Personal Agent 会涉及大量个人隐私，甚至需要访问我们的账户、调用支付等权限。**

如果用户不信任它，就不可能放心把生活中的重要事情交给它。

说实话， **至少在我自己的心智里，目前愿意比较放心地授权使用的 Personal Agent，背后主要还是蚂蚁、腾讯、字节、阿里这几家大厂。**

当然，这只是我个人现阶段的信任偏好，具体还得看产品的权限设计和安全措施。

这部分我就不继续展开了，免得有同学说是广告。

**蔡伟这期分享的信息密度确实非常高，而且从服务业的角度，让我重新理解了 Personal Agent 的机会在哪里。**

记得主持人张小珺问蔡伟，未来究竟是通用 Personal Agent 更有机会，还是垂直 Personal Agent？以及工作场景的 Agent 和生活场景的 Agent，最终会不会融合到一起？

其实这些问题，我过去也问过不少人，但一直没有得到特别明确的答案。

**蔡伟的回答是，这些事情现在很难预测，最终的市场格局，其实都是在商业竞争中打出来的。**

就像微信、淘宝、抖音这些产品，最开始都有自己起家的业务。但这么多年，大家也一直在尝试进入彼此的领域。

微信做过电商，阿里尝试过社交，抖音后来也把电商做起来了。

但你会发现，即便这些公司都有非常强的技术、资金和用户基础，最后也没有哪一家公司能够包揽所有业务。

**大家在不断竞争中，逐渐形成了各自的优势领域，然后进一步形成了分工。**

还有中美的电商也是这样。从用户需求来看，中国人和美国人买东西，基本诉求其实差不多。但最后形成的电商市场格局却很不一样。

中国的电商相对集中，主要由淘宝、京东、拼多多、抖音等大型平台主导。美国虽然有亚马逊这样的超级平台，但同时也有大量品牌独立站，整个电商生态相对更加分散。

为什么会这样？

其实很难单纯从用户需求或者技术能力来解释。 **这里面有市场竞争、商业环境，还有长期形成的用户习惯等各种因素。**

所以，Personal Agent 未来到底会由几家通用产品主导，还是会出现大量垂直 Agent，我觉得现在确实没办法下结论。

**最终还是要看各家公司能够提供什么样的产品体验，能够连接多少服务，以及竞争之后会形成什么样的市场格局。**

至于 Personal Agent 和 Work Agent 的关系，短期内肯定还是会并存。因为工作和生活本身就是两类不同的场景，用户需求、产品体验，甚至数据安全方面的要求都有区别。

这也是为什么，现在几个大厂都在同时布局这两个方向。从目前的情况来看，两类产品都有自己的市场。

至于未来会不会融合，或者其中某一类产品逐渐成为更大的入口，我觉得蔡伟说得挺对。 **这些事情最终会通过竞争找到一个平衡点。** 没人能预测市场。
