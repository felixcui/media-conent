## 一、人声与口播

## 01 纪录片旁白

想做纪录片、企业宣传片、或者历史人文类视频，最缺的就是一口“有分量”的旁白。豆包工作直接按描述生成，性别、年龄、语速、气质都能指定，出来的就是带情绪的解说声。

技巧：人声描述里至少写三样——性别年龄、语速节奏、音色气质，比如“沉稳的中年男性，语速缓慢有力，带一点磁性和沙哑”。想要更有氛围，在描述里加一句背景铺底（“低沉的弦乐铺底”），整段就高级起来了，不然纯人声会有点干。

```
沉稳的中年男性，纪录片旁白解说风格，语速缓慢有力，带一点磁性和沙哑，背景是低沉的弦乐铺底：“在世界屋脊的尽头，有一片被时间遗忘的土地。三千年来，风雪没有改变它的轮廓，却改变了所有踏上这片土地的人。今天，我们将沿着古老的商道，寻找那些仍然活着的传说。”
```

## 02 双角色对话

写短剧、做电台节目、配情景小剧场，都需要“两个人说话”。豆包工作能一次生成完整的双人对话，连环境音和动作声都带进去，省掉你找两个配音演员的功夫。

技巧：直接用“角色设定：台词”的格式写，每个人物先交代性别年龄和语气（“青年女性带着一点着急”），再用冒号引出他的话。背景环境也值得写一笔（“咖啡馆、轻柔的爵士乐”），模型会把环境音和台词混在一起，出来的就是一整段戏。

```
咖啡馆内的双人对话场景，背景有轻柔的爵士乐和杯碟轻响。
```
```
青年女性带着一点着急：“你到底来不来啊？电影还有十分钟就开场了。”
```
```
青年男性懒洋洋地：“来了来了，路上堵车我也没办法。要不你先买两杯奶茶？”
```
```
女性叹气：“你每次都用这个理由……算了，老位置见。”
```

## 03 带货口播

做直播、短视频带货的都知道，口播脚本一念出来就分高下。豆包工作直接生成“带货主播式”口播，语速、情绪、节奏都是直播间那味儿，还能把产品卖点嵌进话术里。

技巧：想要直播间感觉，描述里写“语速快、节奏带感、像短视频口播”，再塞几句电商套话（“家人们”“三、二、一，上链接”），模型一听就懂。背景加上“轻快的电子音乐”，成品直接能当样片。

```
活泼热情的带货主播女声，语速快、节奏带感、像短视频口播，背景有轻快的电子音乐：“家人们！这个夏天你还在被蚊子咬到怀疑人生吗？看这个！便携驱蚊器，小巧到能挂钥匙扣，续航整整三十天！现在下单，前一百名再送两盒替换芯！三、二、一，上链接！”
```

## 04 温柔服务语音

做客服系统、银行或 App 语音播报、酒店问候语的，需要一口标准又温柔的“服务音”。豆包工作生成的客服语音吐字清楚、情绪稳定，还能按你的业务话术来。

技巧：“微笑感”是客服声的灵魂，描述里直接写“语气耐心带着微笑感”，出来就有那味儿。话术写成问答互动式（“请问有什么可以帮您…我帮您查到…您想改到…还是…”），演示更完整。

```
温柔亲切的年轻女性客服声，语速适中、吐字清晰、语气耐心带着微笑感：“您好，欢迎致电云上旅行。请问有什么可以帮您？嗯，好的，您是想修改航班时间对吗？我已经帮您查到，可以免费改签一次，您想改到明天下午两点的那班，还是后天上午的呢？”
```

## 05 多语言配音

出海做 App、做多语言广告、做海外账号的，需要同一句话的多语言版本。豆包工作一段话直接生成中、英、日等多语言配音，发音还挺标准。

技巧：把各个语言写进同一段描述里，标好“中文：”“English：”“日本語：”，模型会一段一段切换。专有名词（Tokyo、東京）写标准写法，发音更不容易翻车。

```
女性声优多语言配音，同一句欢迎词分别用中文、英语、日语说出，语气专业亲切、像机场广播或应用欢迎语。
```
```
中文：“欢迎来到东京，祝您旅途愉快。”
```
```
English: "Welcome to Tokyo, have a pleasant journey."
```
```
日本語：“東京へようこそ。良い旅をお楽しみください。”
```

## 06 特定音色设计

做 AI 助手、做游戏 NPC（非玩家角色）、做虚拟人，需要“非人类”或特征鲜明的音色。豆包工作用“设定为…的音色”一句话就能锁定声线。

技巧：写“设定为带有金属质感的机器人音色，低沉、略带电流嗡鸣”，模型立刻切换角色。想让声音更像某个风格，就把材质感、空间感写具体。

```
设定为带有金属质感的机器人音色，低沉、略带电流嗡鸣，像科幻电影里的 AI 助手，一字一句平稳地说：“欢迎回来，指挥官。系统已为您完成今日的日程整理，共有三项待办事项，是否现在开始汇报？”
```

## 07 声音叙事短剧

广播剧、有声小剧场、音频短剧，本质就是“声音版的戏”。豆包工作按剧本生成带场景、动作、对白的完整音频片段。

技巧：像写剧本一样写描述——场景+动作音+角色台词，动作用括号标（“（背景雨声渐大，一声雷响）”），台词写清角色和语气。生成的音频直接就是一段能听的戏。

```
一个完整的声音叙事短剧片段：雨夜街道，脚步声急促。青年男性喘着气说：“等等！你别走，听我说完——” 脚步声停下，青年女性转身，声音带着委屈：“你每次都这样，说好了九点，你几点来的？” 男声压低：“路上出了点事……但我真的来了。” 背景雨声渐大，一声雷响，两人沉默片刻，女声轻轻说：“……先进来躲雨吧。”
```

## 二、音乐与旋律

## 08 短视频 BGM

做短视频的都知道 BGM （背景音乐）决定完播率。豆包工作一句话生成原创 BGM，风格、情绪、节奏随你指定，还不用担心版权。

技巧：描述里写清“风格+情绪+节拍感”，比如“轻松明快、节奏感强、带电子律动和吉他扫弦”。想要纯伴奏就明说“无歌词”，不然模型可能给你塞进人声。

```
轻松明快的短视频背景音乐，节奏感强、带电子律动和清爽的吉他扫弦，像美食探店或旅行 vlog 的 BGM，无歌词，整体欢快元气。
```

## 09 AI 歌曲

想写首原创歌曲？副歌、旋律、歌词一起出。豆包工作按你给的歌词和声线描述生成演唱版，做个人单曲、品牌主题曲的 demo 都够用。

技巧：把歌词写出来放进描述里，再写清演唱者声线（“甜美的年轻女声”）和伴奏（“轻快的吉他伴奏和鼓点”）。副歌部分要朗朗上口，模型会顺着旋律唱出来。

```
甜美的年轻女声演唱一段原创流行歌曲副歌，旋律清新朗朗上口，带有轻快的吉他伴奏和鼓点，唱：“天空忽然放晴，像你出现的天气。把心事都装进风里，跟着彩虹去旅行。”
```

## 10 片头配乐

品牌片、宣传片、电视栏目的片头，需要一段“有起承转合”的音乐。豆包工作生成 15 秒级别的片头配乐，从铺陈到高潮再到收束，一气呵成。

技巧：音乐也要写“剧情”——描述里写清时间结构：“从轻柔的钢琴渐强到激昂的弦乐与鼓点”，再要求“结尾干净利落的重音收束”。广告片头最怕音乐戛然而止，把收尾写出来就稳了。

```
恢弘大气的广告片头配乐，从轻柔的钢琴渐强到激昂的弦乐与鼓点，像科技品牌或运动品牌的品牌片开场音乐，时长约 15 秒，无歌词，结尾有干净利落的重音收束。
```

## 11 儿歌

技巧：写“童谣、木琴和铃鼓伴奏”，再给一段押韵的重复句式歌词，儿歌感立刻就出来了。想更讨喜就写“温柔又活泼的语气”。

技巧：写“空灵的钟磬声、长音弦乐、极慢节奏、留白多”，这类描述模型很稳。想要流水、风铃这类点缀，一并写进去就行。

## 13 视频配音轨

给视频配一条完整的音轨：旁白、BGM、音效一次到位。豆包工作能把“背景音乐+人声旁白+现场音效”合成一条完整音频，省掉剪辑台上不少活。

技巧：一个 prompt （提示词）里写全所有声音层——“背景音乐打底，叠加旁白，穿插音效”，再用括号标注音效落点（（背景：油锅滋啦一声））。模型会按顺序把整条音轨排出来。

## 14 拟音音效

做短剧、做游戏、做播客，最缺的就是“声效库”——开门、脚步、雷声，一个一个找太累。豆包工作按你的顺序生成一整条拟音音效链。

技巧：把音效按时间顺序写成“先…然后…最后…”的叙事（“老旧的木门吱呀一声被推开，紧接着是缓慢的脚步声…最后是远处传来的一声闷雷”），模型能串成一条完整音效链，连气氛都给你配好。

技巧：环境声要写“分层”——车流、喇叭、交谈、广播、街头艺人各来一笔，模型会自动叠出层次。加一句“傍晚市中心步行街的氛围”，画面感就出来了。

## 17 白噪音助眠

助眠、专注、自习场景的刚需。豆包工作生成的白噪音稳定持续、无突兀变化，直接放 App 里当背景音都行。

技巧：核心就四个字“均匀稳定”——描述里写“节奏平稳、无突兀变化”，模型就不会给你整出吓人的突变音。风扇声叠雨声这种组合很出效果。

## 18 有声书播客

做有声书、做播客、做知识付费，朗读音是最值钱的生产资料。豆包工作把你给的文字变成有情绪的有声朗读，深夜电台感、讲故事感都能指定。

技巧：描述里写清朗读气质（“沉稳知性、语速舒缓、带讲故事感”），直接丢一段原文进描述里，模型就照着念。做长内容可以先分段生成再拼接。

## 19 广告宣传片

一条广告的完整声音包——开场鼓点、男声广告词、转场音乐、收尾音效，豆包工作一次合成。做宣传片、TVC 创意 demo 的，直接省掉大半后期。

技巧：把声音的“剧情”写清楚：先什么、再什么、最后什么（“开场电子鼓点渐强→男声念词→转明亮管弦乐→女声接词→结尾 logo 音效收束”）。节奏感写明白，成品就有广告片那味儿。

## 20 游戏角色语音

做游戏、做配音 demo、做角色设定展示，需要角色语音包。豆包工作让同一个角色一次说出多句不同情绪的台词。

技巧：描述里写“用武侠风格说三句台词”，再逐句标好语气（“第一句激昂…第二句轻笑…第三句低声带警告”），同一角色的声线会保持一致。做 NPC 语音初稿效率拉满。

山巅剑客的游戏配音场景

游戏角色语音包：一个豪爽的年轻男性剑客，用武侠风格说三句台词，语气从激昂到低沉变化。第一句：“来者何人？报上名来！” 第二句（轻笑）：“就凭你，还拦不住我。” 第三句（低声，带警告）：“我最后说一次——让开。”
