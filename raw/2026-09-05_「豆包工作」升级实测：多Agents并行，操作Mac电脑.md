# 「豆包工作」升级实测：多Agents并行，操作Mac电脑

**作者**: 夕小瑶编辑部

**来源**: https://mp.weixin.qq.com/s/ApPonAcFp7WByllNo49ToQ

## 摘要

文章实测了“豆包工作”新升级的两项功能：多Agents并行与Mac电脑本地GUI操作。前者可由主Agent将复杂任务拆解并委派给多个子Agent同时执行，最后回收汇总各子报告，还能自动识别报告间的信息冲突；后者能看懂电脑屏幕并用鼠标点击执行操作。

上周，苹果把新款 Mac mini 的起售价从4499元抬到6999元，一口气涨了2500块。

我对着官网页面算了半天账，还是决定换一个新的。

但换设备最烦的是花钱之前的选择比价。

芯片、内存、硬盘怎么配，官网、Apple Store 和自营渠道谁便宜，教育优惠和以旧换新能不能叠，这个活儿至少要耗掉我一个晚上。

这两天，同事一直安利我试试豆包工作，它有独立的logo和端侧应用，还接入了飞书里，能连接飞书里的工作资料。

等于是把找资料、研究、数据分析、办公文件串在一条任务链里，生成的文档、表格和 PPT，继续带回飞书里处理，非常方便。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/0hd8MxUumHOWsqPkiaMj64QZJNpqw0HRUictYPWkEFa4kgPmyGCibBQonGHQvOEeic94LwxqrnFpuwqBhN8hLdesVtJpXKZwxgTzuDTpz8tnTNk/640?wx_fmt=png&from=appmsg)

恰好，豆包工作这两天新增了两个功能。

一个是 **多Agents并行** ，能让豆包工作召唤几个子Agent同时干活，最后由主Agent 回收汇总。

另一个是 **操作电脑** ，在MAC电脑上，豆包工作可以实现本地GUI操作，看懂电脑屏幕，用鼠标点击&执行一些操作。

这俩功能非常适合这种日常调研、文件梳理的工作。

所以这回，我把调研的活儿扔给了豆包工作。

## ◈1、多Agent并行工作：高效调研

我把自己的需求告诉了豆包工作：

> 整套预算不超过 12000 元，主机、显示器、键鼠和必要配件都算在内，主要用来剪 4K 视频、跑本地模型、写东西和轻度开发，打算用五年。

豆包工作能一次性召唤四个子Agent 分头查。

1. 配置 Agent：看苹果官网和可信技术资料，整理在售机型的芯片、内存、硬盘和接口。
2. 性能 Agent：找真实配置水平，厂商宣传、媒体实测和它自己的推断要分开标。
3. 配件 Agent：在预算里配显示器、外置存储、键鼠和线材。推荐一套配置和一个购买时机。
4. 价格 Agent：对比苹果官网、Apple 官方旗舰店和主流自营渠道的价格，查询近一年的常见优惠节奏，判断现在购买还是等待促销更合适。
![](https://mmbiz.qpic.cn/mmbiz_png/0hd8MxUumHOl2yVP4JWhgby69xh3hJnW9SbrKmL9JJ20KjImbU8YeSmibJzoTGiaJXbvPfD5nIJ68AI395yUxxtpEs1rBFicJgzxDibQft82xics/640?wx_fmt=png&from=appmsg)

任务一发出去，主Agent先把题面梳理了一遍，然后把活委派给一个组织者Agent。

组织者 Agent便开始牵头开工了。

画面右边能看到配置、性能、价格、配件四张任务卡一起亮起「已开始工作」，左边的对话框还提醒我，等待期间可以继续发别的消息。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHOSrRv7yhUVCLeiceow0DtSx7H2R6Ta8TSLRlYTDh0ia8u6DwpbkhVEpviaf2u5OjWJtZK3yvE51nx4oswDkurtX0ficqgz5ibJhD1Y/640?wx_fmt=gif&from=appmsg)

这就是多 Agent 并行的样子。

四路调研在同一条时间并行工作，我不用干等，也不用盯着谁先谁后。

![](https://mmbiz.qpic.cn/mmbiz_gif/0hd8MxUumHOediciceoiagb2PHZQpSxF30K47SEK1b8QdFQGicwknzM1MUDjm91OsowDAvlB8VutgPs2zPnpOWY5pFd8Bpc3WIs067W9gKHH1jU/640?wx_fmt=gif&from=appmsg)

每个子 Agent 交回一份独立报告，能单独点开。

四份报告回来后，主 Agent 没有直接拼接，它竟然识别到了互相之间的信息冲突。

![](https://mmbiz.qpic.cn/mmbiz_png/0hd8MxUumHPjDVrXvmcGZLkcYHtiaMKZCfdaUISEvicK48DHQI3u8ZpvudJUE5lTibchYiagMIy5B1Yus2zibdocoMfmnCODymvVTnJgAEwMSCtA/640?wx_fmt=png&from=appmsg)

冲突一共三条。

第一条，M4 已经不在售了。两个 Agent 说苹果官网已经下架，另外两个说渠道清仓还能买到。

第二条，配件 Agent 的整套方案是按 M4 主机 7499 元配的。M4 要是真下架了，这套方案就不成立。

第三条，M6 要到9月22日才发售，现在只能预购，也没有任何独立评测。

主Agent 的裁决是，以苹果官网实际在售为准。

![](https://mmbiz.qpic.cn/mmbiz_gif/0hd8MxUumHMVCrLUWjpFTDvvf604AaRkqsRSZBG2LZqibrL69gq2QqrqWmNW1rI8dic7UWicxQ2ZKGjs5o7AUiaibxaiboE7mHNenQl8znon57T5I/640?wx_fmt=gif&from=appmsg)

最后，落下来方案，主Agent 建议我购买M6 版、24GB 内存加 512GB 硬盘，现在预购叠加国补，整套桌面 11596 元，预算还剩 404 元。

如果想具体看到一些细节，四个子 Agent 各自的小结论也都留在报告里。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHOq1t5kicagN4YsnPLaGxZz5n8o39mEvCQg1SehjOicQib61Jtu5DRvDhCeobTNbweOxZf1NXEwicqHNKCfZZ2a0MCKmVIgnrXY8Dw/640?wx_fmt=gif&from=appmsg)

配置Agent说，大号内存买不起，硬盘可以上512；性能Agent表示，24GB 跑本地模型的极限是 22B。但 M6 还没有实测数据。

价格Agent 的结论是，M6 各渠道都在预购，国补最多减 1500 元，教育优惠全年有效，所以现在就能买；配件Agent给的配件清单也非常齐全。

综合下来，结论就相当完整了。

看来，并行查资料这一步，豆包工作的多Agent方案比单Agent靠谱！

顺便跟大家说一下怎么用这个多 Agent功能。

现在，你只需要打开豆包工作，将需求描述清楚，豆包工作会自己启动多 Agent 并行模式。

![](https://mmbiz.qpic.cn/mmbiz_png/0hd8MxUumHOibIx5JAOS8ic6ia8sdkWltfEbcOnpTWAXVChp6eH80LibeDFWj2TmibhsyXtejqIevKcaufk4yfo5KYs0FbIWaRLF4vibeW2TZaalY/640?wx_fmt=png&from=appmsg)

此外，也可以在提示词里直接写一句「使用多 Agent 并行处理任务」手动触发。

## ◈2、操作电脑：自动发邮件

配置定了，下一步是把采购需求提给财务。

这种活以前都是我自己截图、贴备忘录、写邮件。

但现在，豆包工作也学会了操作本地应用，直接换它来做。

我要求豆包：

> 打开飞书邮箱新建一条「Mac mini 购机参考」，把信息整理成清单，再把截图插进去。打开邮件给 tg@wmxiaomu.com 写一封草稿，主题「Mac mini 配置和价格参考」，截图作为附件。最后存到草稿箱，等我确认之后发布。

它的操作我剪成了三段动图，非常丝滑。

第一步是写收件人。

豆包工作在飞书邮箱里点开新邮件，光标进到收件人栏，把地址敲完，地址立刻变成一个可识别的收件人标签。

![](https://mmbiz.qpic.cn/mmbiz_gif/0hd8MxUumHPEL32o9ycVzBaEw4tMPN6Eibv4gOkXn86SEyiczBkAvxibSfdGw8x50OvR0oY2XZGYHTrw0X3WY1Oicu6og843FIibpEgvln93oxn8/640?wx_fmt=gif&from=appmsg)

第二步是写主题和正文。

指针移动到主题框框，直接写上「Mac mini 配置和价格参考」，然后顺势在正文粘贴上编辑好的邮件内容，非常丝滑。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHPEsMZWoKPBQI3bPby9vzUAVvTF2tYYpo0zgRKXfI4aY77cbpjwhvYCsxMcKlz0CrPp3JcT8yld9UmIx3pCnDhJ8dbEuibAheAM/640?wx_fmt=gif&from=appmsg)

第三步是添加附件。

它在系统的文件选择器里一层层往下点，选中那张 Mac mini 官网截图，点「打开」，附件卡片就出现在正文下方。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHNaA2m3Y8jILznSYEjibjAia2V9Es6XHlFYMvdJukTAt5Cf8rWibOibLCNcdkDRCHQ4eNu6YdaVgyhTtnKWwh6bOHYsZAeF9HZFiaCg/640?wx_fmt=gif&from=appmsg)

完美，最后，我只需要确认，手动点击发送邮件就好了。

邮件是给同事的，下一件事是给家里人的。

正好我妈说她之前的电脑已经卡的不能用了，她统计学生成绩的时候Excel卡半天，我的新机器定了，旧的这台 Mac 周末要送去我妈家，走之前得把它改成老人能上手的样子。

## ◈3、Mac系统：跨软件执行任务

给老人用的电脑要改的东西很具体，字要大，鼠标要看得见，桌面上要有一个一点就开的入口，浏览器打开就是她要看的戏曲频道。

于是，我干脆让豆包把界面显示、鼠标指针调大两级，再把戏曲频道设成Safari的主页，放进收藏夹。

这些设置散在系统设置、辅助功能和 Safari 三个地方，我自己来也得点半天。这次交给豆包工作。

第一项是显示。它打开系统设置，从通用一路点到显示器，在那排分辨率选项里往「更大文字」方向挪了两档，停在 1147×745。

动图里橙色箭头跟着蓝色选中框从「默认」往左走两格，设置界面也跟着放大了两次。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHNtw0biayoO8EPLfRSFlmJKhTlaeWQClUricUlibwkOibFvonPic4iarcrQTLSk4nRWCzsGOKR73oe7SZcsIN9Hyc6ibiakhYiaXicOUUsZE/640?wx_fmt=gif&from=appmsg)

第二项是指针。它进辅助功能，把「指针大小」的滑杆往右推了两级，蓝色进度条跟着变长，画面里的黑色指针也明显变大，橙色箭头先指滑杆，再指最后的指针。

老人最常抱怨的就是找不到鼠标，这一项比放大字体还要紧。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHOkL4at0LW12Y3gvWibe81eJiamd4wv49hRnff4324dGhltbicR1NzWUnvEMxPnNw14EHsT5vSE2MaOd5VXgc73ia0eOxbibiaKEAV4U/640?wx_fmt=gif&from=appmsg)

第三项是主页。它在Safari 里打开央视网，找到 CCTV-11 戏曲频道设成主页，新开一个窗口验证能打开，再从书签菜单把页面加进个人收藏。新窗口一开，戏曲频道直接出来。

![](https://mmbiz.qpic.cn/mmbiz_gif/0hd8MxUumHNpkbKgyh4o1BRwicEomX5gj4tCN9o68nKomFojpraUianaYfJRgTO7edNfeVu7hiauyibPb2wEhvXiaNS9LMwnAuiar9LOCZE1wyUHc/640?wx_fmt=gif&from=appmsg)

它没有绕路去改任何配置文件，也没有动任何应用，Finder 和废纸篓都保持原样。

给长辈用电脑，宁可它慢一点，也不要它自作主张去改配置文件。

三项做完，每一项它都回到对应位置重新看过一遍，最后给我列了一张清单。

## ◈4、最后把我自己的日常活也丢给它

长辈的电脑安顿好了，我自己每天还有件固定的活。

我做了一个南亚新闻日报，每天要把当天的公众号内容拆成几条微博，逐条配图、设定时、发出去。这活不难，就是烦，七条要重复七遍。

这次，我让豆包工作来做这个任务。

既然可以操作电脑，那操作发定时微博这个任务，我也交给它。

> 使用「South Asia Weibo Daily」技能，发下今天的微博 [https://mp.weixin.qq.com/s/oeawmSyWbbRZAdoRVJPP0w](https://mp.weixin.qq.com/s?__biz=MzkxNDQyODQ5OA==&mid=2247514340&idx=1&sn=515c86361ded1c4d990453aaada271ae&scene=21#wechat_redirect)

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHMqcrhoukytVMn5GxNY1xwp6u6jjPTXWP6OiblCoYvW0ClHvp4iboyVX03b4iclakqh2rziaSGVdQ3zR1ADwuBYx7HHgkOYqWysBwE/640?wx_fmt=gif&from=appmsg)

一开始，豆包工作还没有拿出操作电脑的看家本领，它就直接一行行写命令，操作发送微博。

可以看到，左边是豆包工作的任务日志，右边是 Safari 里的微博后台。

豆包工作先把正文填进编辑器，再把图片复制到剪贴板粘贴上传相当丝滑。

![](https://mmbiz.qpic.cn/mmbiz_gif/0hd8MxUumHOoSicZrMam2ehfFLEX0Qw5k4OkN0oN5icITibmut7vV2yQXrvia6zN49PT7qoZlcajV9icwjIuicVKd2jd7Z4YecuspGKBp5icHwC4cA/640?wx_fmt=gif&from=appmsg)

接着是第三条，复制、粘贴，设置时间，点击发送，一气呵成。

![](https://mmbiz.qpic.cn/mmbiz_gif/0hd8MxUumHMWkpy6qRAIgmGKsViaxiaul1Y1t4g7szJoDX2icL2JBJyibHRTLw9vAPjukhiaxc2fPHcsVZaib1gz2EEVrA6qB9QaZJd7l3D9yjtXM/640?wx_fmt=gif&from=appmsg)

第四条同样的流程，正文 572 字，时间定到 18 点，图片传完就入队。

右边的队列已经排到三条，每条的发布时间都不一样。

这要是只拿写好的网页脚本来跑，逻辑真要复杂很多了。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHNcIQ51CqHYMyaNma4cCCznVHeAfHwoyHq22dXDK77zvkykTXEKV0sVqVyf6bYw7KAvTJCNiczORE94MzFqR6szZrrftI0tdZJE/640?wx_fmt=gif&from=appmsg)

结果，在第四条的时候，豆包忽然出了岔子。

不知是哪里的问题，图片一直传不上去，豆包等了几秒，换了一种方式还是不行，最后换回剪贴板粘贴才传上去。

看到这里我在对话框里插了一句， **让它用原生操作电脑的能力去做剩下的。**

试试看家本领，原生操作GUI能不能解决这个问题。

**豆包收到指令后，后三条就切换成新的原生 GUI 路线。**

正文靠系统的辅助功能输入，图片用剪贴板粘贴。也相当顺畅。

到第六条的时候，因为定时时间太晚，豆包工作还特意把发送时间跨到了第二天早上，页面日期也跟着改成了第二天。全自动省心省力。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/0hd8MxUumHMxewmTUniadic7dPgVWvjwI1gT5BSjHk6nCUZgFWwEjEdEFwxKFib3icnydVHD7waxoXuZiauficmicJEC44tjlnJsxwBBZ42yOCicyC4/640?wx_fmt=gif&from=appmsg)

最后，七条都定时完成之后，豆包换成键盘翻页把列表滚到底，检查了一遍是否已经完整定时。

它找到第一条卡片。右边七条定时微博一条条排着，从下午1点40排到晚上9点40，其中还有一条排在第二天早上。

完美。

## ◈总结

这一天下来，我印象最深的一幕，是豆包工作在文件选择器里一层层往下点，找需要的一张 Mac mini 截图。

屏幕上的鼠标在动，坐在电脑前的我却没碰它。它点错过一次，退回去，又点对了。和我自己找文件的样子几乎一样，只是慢一点。

以前对 AI 干活的想象，是咱把东西喂进对话框，它把结果吐回来。

中间那段真正花时间的动手操作的活儿，翻网页、切窗口、改设置、一条条填表，还是我来干，现在这种浪费时间的活儿都接手了。

找资料、看资料、做分析、写内容、做文件、协作修改一条龙服务，多Agent并行功能上线后，一些批量处理、分模块生成、多维度调研等等的任务，效率翻倍。

豆包虽然没有我做得快，但不着急的事都能让它接手去干，而且每一件做完，都不用再从头看一遍。

下周四苹果的发布会开完，剩下的调研整理工作，我已经不打算自己干了。
