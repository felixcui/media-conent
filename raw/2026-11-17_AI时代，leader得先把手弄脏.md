## 摘要

AI Coding普及后，仅凭代码产出量已难以判断员工优劣，同样提交十个PR，背后可能是善于驾驭Agent与制造返工两种人。个人价值正从执行转向管理Agent，核心是平衡质量与速度、约束Agent边界、整合多个Agent成果，本质是从执行思维转向系统性思考。判断优秀应看其拒掉Agent哪些产出、上线后返工多少、约束能否复用。Leader同样面临经验快速折旧，判断力只能来自亲手实践，必须把手弄脏。

最近带团队，我越来越常遇到一个问题：我不太确定该怎么判断一个人优秀了。

以前这件事不难。谁代码写得好、写得快，谁能扛下最难的模块，大家心里都有数。执行做得好，就是最重要的价值。

AI Coding 普及以后，这把尺子不太好用了。我自己当 leader，也觉得比以前难。这篇想把这两件事说清楚。

## 一、优秀变得难以分辨

同样一天提了十个 PR，背后可能是两种完全不同的人。

一种是真的在驾驭 Agent：任务拆得清楚，约束写在前面，每个 PR 都自己检查过，合进去就不用再动。

另一种是在制造返工：Agent 写什么就交什么。PR 看着整齐，问题要等到 review 或者上线以后才冒出来，最后还得别人来收拾。

只看产出，这两个人一模一样，差别都在水面下面。

Agent 把单点执行做好以后，“能写出代码”已经不稀缺了。产出量说明不了能力，有时候还会把问题盖住。

同样十个 PR，水面下一个是返工，一个是约束和验证

## 二、个人：从执行走向管理 Agent

那现在比的是什么？我的看法是，个人的价值正在从执行往 management 迁移，只不过管的是 Agent。具体是三件事。

**平衡质量和速度。** Agent 让“快”变得很容易，难的是知道什么时候该慢下来。哪些改动可以放手让它跑，哪些必须自己看一遍，靠的是判断，手速帮不上忙。

**约束住自己的 Agent。** 任务边界、验收标准、不能碰的地方，要先写清楚，Agent 才不会跑偏。约束写得好，一个 Agent 能干的活比你想的多；写不好，它干得越多，你收拾得越多。

**整合多个 Agent 的成果。** 同时开几个 Agent 已经很常见。它们各自交出来的东西，接口能不能对上，假设有没有冲突，合起来还是不是一个整体，得有人站在全局去看。

这三件事背后是同一个转变：从执行思维，转向系统性思考。以前想的是“这段代码怎么写”，现在想的是“这件事怎么拆、怎么约束、怎么检查、怎么合起来”。

价值从“写代码”这一格，挪到了定约束、分派、检查、整合这一圈

## 三、怎么看出一个人优秀

产出量靠不住，我现在更愿意看判断。我会问三个问题。

**他拒掉了 Agent 的哪些东西？** 能说出“这段我没要，因为……”的人，是真的看过，也知道好坏的标准在哪。全盘照收的人，说不出来。

**他的东西上线后返工多不多？** 交得快不难，难的是交出去以后不用回头修。返工最能说明问题。

**他定的约束，别人能不能复用？** 他写的规则、验收清单、给 Agent 的说明，别人拿过去能不能直接用。能复用，说明他想清楚的是这一类问题，不只是自己手上这一个任务。

旧尺子量产出，新尺子看判断

## 四、Leader：时间分配反过来了

个人难，leader 更难。

以前一个 leader 的时间，大头放在中短期计划、长期战略和团队建设上。一线的技术细节交给团队，经验够多，判断就不会太离谱。

AI 浪潮下，这件事反过来了。

工具和做法变得太快，几个月前的经验，现在可能就不成立了。经验折旧这么快，leader 的判断力从哪来？我的答案是：只能来自亲手试过。

所以“把手弄脏”不是姿态，是判断力的来源。你没亲手让 Agent 跑完过一个完整的任务，就很难判断团队说的“这个能自动化”靠不靠谱，也很难看懂一个人一天十个 PR 到底意味着什么。

不亲手试，后果来得很快。团队在聊的新工具、踩过的坑、摸索出来的新做法，你都接不上话。慢慢地，你会觉得自己被团队甩在了后面。

Leader 的时间分配倒过来了

## 五、Leader 的新功课

所以我觉得，现在当 leader 需要更高的精力，至少要同时顾三条线。

**思考。** AI 浪潮下，团队的业务和技术在怎么变：哪些事以后不用人做了，哪些事反而更重要，团队要不要跟着调。这件事没人能替你想。

**动手。** 亲手试最新的工具和做法。目的不是自己多写几行代码，而是让判断有依据，能和团队用同一套语言说话。

**对外。** 放下“我只是技术人员”的心态，主动学 GTM，做个人品牌。

第三条最容易被技术出身的 leader 忽略，我多说几句。

执行变便宜以后，做出来的东西本身越来越不稀缺。一个团队的价值，越来越取决于它能不能被看见：用户知不知道，能不能看懂，愿不愿意用。技术人的价值也一样，需要有人讲出来。

团队的影响力，有一部分就取决于 leader 能不能把它讲清楚。你不讲，团队做得再好，外面也看不到。从这个角度看，学 GTM、做个人品牌是 leader 对团队的责任，和出不出名关系不大。

Leader 的三条线：思考、动手、对外

## 六、写在最后

这些话不是在评判谁做得够不够。我自己也还在学，也在要求自己做这些：抽时间亲手用 Agent 干活，想清楚团队接下来往哪走，也开始写东西，对外讲我们团队在做的事。

Agent 越来越能干，执行越来越便宜。不管是做个人还是当 leader，都得重新回答一个问题：我的价值到底在哪。
