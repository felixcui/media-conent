## 一、全景：这期到底在讲什么

一句话：**这是一份"研究者被模型反复打脸"的清单。** 谷雨的 10 个 Aha Moment 几乎不是行业热点，而是"我原来判定这条路不行 / 不重要，结果被证伪"的时刻——他开场就自己承认"我最近确实被打脸了""这也是很打我脸的一个事情"。

和上一期（庄明浩用 10 个时间点串全年行业演进）不同，谷雨的 10 个点是**四种身份视角的层层下移**：技术判断者 → 体系观察者 → 创业者 → 产品/内容消费者。

```
① 技术判断层（前 4 个）：模型把我的"工程解法"吃掉了
   RSI：startup 不可能 → 但大厂 infra 从资产变负债，neo lab 零包袱反而有加速度
   Computer Use：「手」已解决，瓶颈转到「脑子」（认知层）
   数学：formal verification 不是必需品，scaling 又赢一次
   Continual Learning：memory notes 不是可靠优化算法 → 但模型变强后上限被低估

② 体系层（第 5、6 个）：评价体系失效，智力的定价在重估
   论文/审稿/会议系统坍塌 → 教职优先级下降 → 「十年后教授不如夜店男模」

③ 创业层（第 7、8 个）：学术 taste 需要被市场校准
   从「拿锤子找钉子」到 SPP（solution in search of problem）
   造灭火器 vs 卖砖头：发布标准太高是学术团队最大的包袱
   创业从非主流变成随大流：钱太多，2 billion 估值的 neo lab

④ 产品/内容层（第 9、10 个）：用户已经不在乎"是不是 AI 做的"
   AI 电影：两小时前后一致，弹幕只讨论剧情
   Personal Agent：起来靠的不是技术临界点，是两个产品设计
```

前四条有一条隐藏共性，是全场最有信息量的观察：**被吃掉的都是"补丁"**——挑对的那次再封装成 skill 的 pipeline、formal verification 提供的训练信号、外部 memory 架构，这些都是在"模型还不够强"前提下的工程代偿；模型一强，代偿全部失效。

一句话概括谷雨的立场：**技术侧彻底服膺 scaling（"不得不信"），但对人的位置给出了十年尺度的悲观推论；他的落点不是技术，而是"审美 + 情绪价值"这两件机器短期拿不走的东西。**

## 二、十个 Aha Moments 逐条

### 01｜01:13　RSI：大厂有创新者的窘境，反而成了 NeoLab 的机会

- **原来的判断（很粗暴的两点）**：① 做 RSI 本质是模型叙事，要追最前沿的模型厂——别说新 startup，除了 OpenAI，其他模型厂这么长时间都还在后面赶，startup 上哪做；② 要做 recursive self-improvement，首先得有起点，起点得有自己的模型。
- **被什么打脸**：Recursive 与 Miranda（ASR 音近）的发布。其中一个团队一个人搞三个多月，训出的 pre-training model 比 K3 还强。
- **转折后的逻辑**：AI 的研发能力越来越强，总有一天它写 training infra、写 training recipe 的能力会超过人。**那一天到来时，大模型公司此前积累的 infra 和 recipe，反而可能成为一种累赘。**
- **最具体的例子**：国内某模型厂的朋友说，最近某个已公开的技巧（ASR 记为"score centering"，疑为 reward centering 一类）大家都知道有用、用了可能提一两个点，但为了用它得适配自己的 infra，代价太大，所以不愿意做。
- **neo lab 的结构性优势**：从 0 开始，反正都是让 AI 去搜一套新 recipe、搞一套新 infra，**随时可以迭代它，随时可以丢掉它**——所以加速度可能更大。
- **前提条件**：要走模型叙事、做 full stack 模型训练，必须大量钱、卡、数据。Recursive 和 Miran 确实拿了很多钱。他还看好 GD、Discovery Loop（ASR 音近）等其他 RSI 公司，国内也有一批，可以再观察。
- **一句话**：**创新者的窘境这次不在市场端，在研发端——"过去沉淀的能力"变成了"改不动的负债"。**

---

### 02｜04:28　Computer Use：「手」已经解决，「脑子」才是下一步

- **团队背景**：NeoCognition 一直在做 computer agent。去年的核心问题是泛化性和可靠性。
- **今年的变化**：去年底到今年初，操作层面的问题基本解决完了，**真的泛化了**。主要原因是 coding 的训练规模上去了，能力外溢到各种软件操作和网页操作。
- **新的分层**：现在是「手」基本解决，「脑子」（cognitive level）还没解决。例子——Agent 完全知道怎么点这个按钮，但它不知道**这件事在公司内部该怎么处理**（每家有一套自己的业务流程、审批约定）。一旦认知层清楚了，操作层没问题。
- **注意**：认知层和 computer use 是正交（orthogonal）的，但它最终必须体现在和软件/网页的交互上——数字世界的工作最后都落在 computer 上。
- **为什么是 Aha**：公司刚成立时，花了好几个月去解操作层面的 reliability 问题。当时做法是：**让模型做几次，把做对的那次挑出来，封装成一个 reusable skill**，为此搭了一整套 pipeline。现在这套 pipeline 完全不需要了——直接让 Opus 5.5 自己实现一遍流程，很快，而且**会在过程中自己纠错**。
- **ApprenticeBench（他们刚发布的评测）**：
  - 场景：建筑行业的会计报账，100 道题。每道题背后是不同的公司规则、convention、specific workflow、特别审批流程。
  - **关键设计：100 道题不是独立的**，必须 in a stream 连着做。前面题目得到的反馈和知识，才能支撑后面的题——测的是"边干边学"的持续学习过程，是 meta level 能力。
  - 现有 long-horizon benchmark 的 bias：都在找"特别难、一个人要做半天"的任务。两个问题：难 scale up；且方向可能错了。
  - **谷雨对长程的定义（全场最好的一句）**：真正的长程不是让一个会计把一份账报一个星期，而是**让一个菜鸟员工变成这个公司的老员工，这几个月到一两年的过程，才是真正的长程**。这种长程 scale up 起来才能到达 lifelong intelligence。
- **分数与刷分**：目前第一版最强模型（Claude 最强）已做到 80 分左右；很快会发新版本，最强模型分数会低很多。不容易刷分的原因：① 没公开，别人没法追着刷；② 测的是 meta level 能力，针对特定公司规则去刷对模型毫无好处——"你要真能刷上去，那也确实算积德了"。
- **提分靠什么**：continual learning 能力，这是当下区分前沿与非前沿模型最关键的 dimension。最重要的是"能让模型更好写 memory notes 的数据"。OpenAI 和 Anthropic 都有自己的 recipe；另一种可能是 Claude Code / Codex 这类天然的长 session 本身就伴随这类性质的数据。但 recipe 还不成熟，除这两家之外没有特别好的 solution。
- **团队在评测上的履历**（也是"taste"的证明）：MMMU（多模态评测，OpenAI / Anthropic / Google 发模型时默认使用）、Mind2Web（2023 年 5 月，LLM 时代最早的 computer use / web agent benchmark）及其变体 Online Mind2Web、与清华合作的 AgentBench（LLM 时代最早期的 Agent 任务 formulation 与数据/任务分布资源）。

### 03｜13:10　数学与千禧年问题：Scaling Law 永远值得你相信

- **事件**：千禧年难题被 OpenAI 一个接一个解决。相对去年，"更哈了，放大了 50 倍 100 倍"。
- **两年前的认知**：当时认为数学能做成，是因为有 formal verification、有 Lean 这类形式化系统提供信号。如果让 informal 的 LM 自己嫁接自己，是"左脚踩右脚"，上限不会特别高。
- **实际发生**：数据量和质量上去之后，**去年就已经能用 informal 的方式拿 IMO 金牌**；今年更进一步，千禧年问题基本都能解。至少打破了两年前的认知。
- **结论**：还是某种 bitter lesson，"我们确实认知不足"，**不得不信 scaling**。
- **副作用（全场最沉的一段）**：很多做数学的人因此陷入虚无主义——他们本是世界上最聪明的一群人，做的是对智力要求最高的一件事，**结果智力突然变得不重要了**。
- **Koji 的反问**：解决问题本身的目的也许不是解决问题，而是过程中发现的方法、积累的 know how 更重要；就像运动员追求身体极限，不可能比机器快，但这对人本身就是意义。数学以后可能像棋类运动一样，变成"人挑战自己智力的极限"。
- **一个荒诞侧写——拼豆自习室**：几百种颜色、各种图纸、全部工具齐备，按小时收费，每人一个小隔间。画面像一个安静的工厂，每个人都在格外认真地劳作——**付费劳作**。谷雨："这个模式不错，我们公司可以退钱。"（Koji 总结：很多时候我们做的事不是机器做不到，而是做这件事本身对人就有价值、有意义、有快乐。）

### 04｜16:18　Continual Learning：我曾公开说 Memory Notes 不行，被打脸了

- **原来的观点（很"research"）**：通过 rewrite memory notes 的方式做 continual learning 肯定不靠谱——它不是可靠的优化算法（not a reliable optimization algorithm）。
- **被打脸的地方**：加上 scaling 或者继续训练之后，它还是能行。原因是双重的——computer use 到了临界点（见第 2 条），叠加**基于 memory notes 做 learning 的上限被显著低估了**。
- **修正后的表述**：它确实仍然不是一个可靠的优化算法，仍然有问题；但过去最大的瓶颈是"写 memory notes 这件事很大程度被模型自身能力 bottleneck 住了"。模型越强，这件事的上限就越可观。
- **但必须声明**：so far 真正在这方面比较强的只有 Anthropic 和 OpenAI，其他家做得都不行。
- **归纳（Koji）**：前 3~4 个 Aha 都和模型的快速进化有关——**颠覆了"模型做不到，所以我们需要工程手段或其他 learning paradigm 来补"这个前提**。谷雨："今年确实要更加相信模型的 scaling，而且迭代也更快了。"

### 05｜17:55　学术会议体系快要坍塌了，然后呢

- **时间判断**：2023 年就有这个趋势，到 2026 年**临界点真的到了**——评价体系、投稿系统、会议系统"彻底崩塌"。
- **个人行为的变化（最硬的证据）**：已经**一年半没有投过任何一篇论文**（不想投，不是高优先级）；已经**半年多没审过稿、没当过 AC**——"感觉这对我的时间并不是很尊重"。
- **原因**：大量的 AI slop、大量灌水。当一个 AC 拿到一个 batch 16 篇，最后真的拿得出手、质量说得过去的，也许就一两篇。
- **后果**：论文数量已经完全不构成对人的考核依据（"以前我也不认同数数，但现在你已经完全没有任何相关性了"）。
- **招人看什么**：更多看聊的情况——问做过的事、看他对公司正在做的事的理解，很容易看出来；流程里会让他做一次 research presentation，逻辑表达、QA 反应、对问题的理解都在里面。
- **那什么体系会重建**：最好的评估是**同行评议**，不应该是一个量化指标。但现在的审稿过程恰恰不是他说的那种同行评议——**审稿人没有 taste 门槛，本科生也能当审稿人**。他参照的是美国院校招人的 job talk：candidate 讲，院系里的 senior professor 和比较强的老师给意见，判断这个人本身怎么样。
- **现实**：体系的建立有滞后性，中美学术圈都还在按之前的惯性走。**结果就是进大学当教职的优先级在往后排，尤其是 AI。**
- **原因很现实**：机会和钱。一个 AI PhD 去 frontier lab 或 neo lab startup 能赚很多钱，在学校待遇差很多、资源少很多，资源少很多事也做不了；同时还叠加了评价体系的问题。

### 06｜21:37　大学教授与夜店男模：十年后谁的社会地位更高

- **原话**：跟朋友开玩笑说，"可能十年之后教授的社会地位不如夜店的男模"。**"我真的这么觉得"**，不是夸张比喻。
- **推理链**：当你的智力不再值钱的时候，可能你的长相跟身材更值钱。人类历史上大部分时间（尤其进入现代文明之前）**体力**更值钱，强壮更值钱；机械时代到来，强壮变得不重要；进入数字世界，**脑力**变得重要；现在 AI 是"数字世界的机械"，脑力也变得不重要了——那就会有一些新的东西变值钱。**情绪价值在短期内是机器很难取代的。**
- **佐证**：全世界卖得最好的两种减肥药的收入，**大于这些模型公司的收入**。减肥药只要有效果、没副作用，就很容易成为世界首富的生意。
- **给 PhD 的建议**：**不给建议，自己开心就好。** "我又不知道你追求什么、看重什么，你自己想清楚就行。"
- **什么人今天还适合读 PhD**：想读的就可以，不需要非常理性。**"想做一件事去做，就是一种理性；你想做不去做，我不知道这为什么算理性。"**
- **为什么创业（三点，都很"非理性"）**：
  1. 一路读计算机，但**从来没有一秒钟想过去大厂**。受不了固定的上班与作息时间，需要灵活性，"我不需要工作和周末的边界——我在那个状态的时候去做事，不在那个状态的时候可以不做"。
  2. 对做的事情方向要有更大决策权，"而不是去完成别人给你的一个使命"。"我很难为别人工作。"
  3. 对风险没有概念，做一件事就是想做，不计较代价。
- **家庭变量（Koji 追问）**：父母确实没有世俗层面的要求，不催人生节点，也不催结婚，"所以可能还是有一定的安全感"。

### 07｜25:34　创业做 NeoLab：火烧起来时，该造灭火器还是先卖砖头

- **学术侧的优势从哪来**：导师（ASR 记为"苏玉"老师）带领的组在学界口碑好，核心是 **vision 和 taste 不错**。具体表现是不做"拿锤子找钉子"——不会先想一个奇怪的算法/设计，再去找它能用在什么问题上然后写 paper；而是真的从 fundamental issue 出发去想技术问题。这也是他们能在 LMM/Agent 时代做出开创性工作的原因。
- **Aha 的地方**：**放到创业上，自己反而成了那个"拿锤子找钉子"的人**——solutions in search of problems（SPP）。
- **为什么**：做学术研究，只要在一套技术体系内能闭环、能自洽就行了。但做 startup **光自洽不行，光自洽是自娱自乐，你需要和 market 一起完成闭环**——还得想这些 fundamental problems 能解决别人的什么问题、能带来什么样的 business value。
- **交的学费**：learning 确实是当下 AI 的一个 fundamental problem，但它放到 market 里、放到产品里应该是什么形式、应该解决什么问题——这是过去几个月到一年在补的课。
- **VC 的那个理论（全场最锋利的比喻）**：当一个人头上着火，他不会等你给他一盆水或者一个灭火器——**他手头有个砖头，也得先把头上的火拍灭**。
- **投射到业务**：**他们对"发布"的标准太高**，总想 release 一个自己特别满意、特别 solid 的东西。但作为公司，有时候真的要先发一些不那么成熟的，先把闭环跑起来，甚至"先把牛吹出去都行"。**"我们在这方面确实太本分了。"**
- **节奏的重要性（Koji）**：不能 bluff（说了 deliver 不了），但节奏很关键——**说得早，你会成为第一个 momentum 的创造者，后面有很多红利，当然最后要不断 deliver**。
- **正面样本**：马斯克。"硅谷这种 fake it till you make it 的机制。"
- **延伸：高中生不读本科直接工作**——他认为合理。在北京上海这类教育资源丰富的地方，可以很早去做真正有价值的事、接受真正有价值的训练。国家教育体系符合国情，但对个体来说，前十几年并不是真的在磨练能力，**更多只是为了完成筛选**。如果能把这段时间用在真正有价值的事上，高中阶段就能做出很有意义的贡献。但这不会成为大众化的事，对教育资源和环境要求太高。

### 08｜30:44　等一下，教授和 PhD 们创业怎么成了一件随大流的事

- **现象**：过去很长时间，创业是"非主流路径"，是和大多数人想法不一样的人才会走的路。但过去一年，他开始**频繁听到身边有人说"大家都在创业，我周围人都在创业，我也想去创业"**——"就感觉好诡异，什么时候创业成了一个随大流的事情？"这是这一年里让他"哈"了很多次的事。
- **原因：趋利，且钱是真的多**。他"到今年 6 月才知道国内原来会投这么多钱"——之前大家的印象一直是硅谷比国内钱更多。
- **对比数据**：NeoCognition 作为 aging（早期）startup 拿 4000 万美元种子轮，在硅谷已经算挺大（最常见的种子轮是 500 万 ~ 1000 万美元）。国内 2023–2024 年创业，很厉害的老师也就拿 500 万 ~ 1000 万美元。但**今年上半年国内一些 neo lab 直接 2 billion 量级的估值**，这对他"非常非常震惊"。（他猜测可能与国内房地产下行、资金没有去处有关，但"这个可能科技口的老师看得更清楚一点"。）
- **Koji 的立场**：鼓励创业创新 in general 对一个社会是好事，而且让掌握最前沿技术、最有想法的一群年轻人**没有压力地**得到足够多的资本去尝试，肯定是好事情。
- **"真的没有压力吗"**：多数人不签回购、不签对赌，所以压力不是个人财务上的——**更多是"我会不会浪费几年时间"这种压力**。

---

### 09｜32:47　AI 电影：我居然在 B 站看入迷了，忘了它是 AI 拍的

- **能力判断**：最近几个月 AI 视频生成达到了他此前没想到的高度——**真的能做一段两小时左右、前后非常一致的电影**。
- **具体案例**：B 站一位 up 主（ASR 记为"龙小胖"），把他小时候很喜欢的香港僵尸片、把已故演员林正英"搬回来"，做了一部新的僵尸片，两个多小时。**人脸、情节、衣着从头到尾几乎完全一致，七八个角色都保持住了。** 对比大半年之前：做几分钟的 AI 视频，人脸都在不断变。
- **最关键的观察**：他是**真的把它当电影在看**，不是"来了解一下 AI 今天能做到什么程度"。**弹幕全都在讨论剧情，没有人讨论 AI。** B 站会声明 AI 创作，所以大家都知道它是 AI 做的——**但大家不 care 它是怎么产生的，care 的是这个 deliverable 做成什么样。**
- **他的结论**：对影视从业者来说这可能是更大的 Aha。"最终大家对于一个事情是怎么产生的可能不是很有所谓，关键还是最后的 deliverable 长什么样。"
- **创作冲动**：还挺想试一试。"这个时代真的很利好创作者——就像 Alex Wang 说的，大家都可以去 dream，想做的事情现在 AI 能帮你去实现。"
- **Koji 的一个科幻设定（顺带被谷雨当场"植入广告"）**：未来算力越来越贵、人变成永生，想获得更多算力来享受生活（娱乐），就要**用记忆去换**——因为记忆是数据，模型还在进化，进化仍然需要吃掉人更多的记忆。所以那是个很悲伤的故事：人在卖掉自己的记忆，换取当下的生活。谷雨："关于怎么样更好地做记忆这件事，可以关注 NeoCognition 后续的工作。"
- **价格锚点**：去年一个拍 AI 短剧的朋友，60 集、一集一分钟（共 60 分钟）的剧本，报价大约 **7 万人民币**。现在 AI 一天能给你写 100 个。
- **那什么会变值钱**：他跟朋友说过一个很粗暴的结论——**未来人只需要两件事：一个是审美（决定正确的方向、前进的路线在哪），一个是美（情绪价值）。**

### 10｜36:25　你可别说，Personal Agent 还真的挺有用

- **判断**：Personal Agent 突然起来了，但**不是技术真的到了什么临界点**（虽然 coding 更强能做更多事、computer use 更强能更好地操作软件和网页，是基础），**更多是两个产品层面的关键设计**：
  1. **会话形态**：ChatGPT / Claude 那种 session-based 的会话管理是**不合适的**。如果把它想象成你的助手，你不可能"说一件事开一个窗口"。必须是 persistent 的单一会话——像微信里每个人一个窗口，从头到尾就是一个。所以他和 Muse 就是一个单独会话。
  2. **拟人感**：产品层面要让它"更像人"——这就是为什么这些 personal agent 都要搞卡通形象（Muse 那个毛绒形象、走各种 PR），一定程度上是在做拟人化。
- **关于 proactiveness**：这本身不是什么新技术。年初 OpenClaw 就有这个 feature，ChatGPT / Claude 的 schedule task 一样能做到——固定时间去看一下邮件、给你推个推送。所以**本质上就是产品和交互体验**。
- **他自己在用什么**：Muse 和 Instinct（ASR 音近）。分工上其实都只是帮他看邮件、看消息——因为在国内，这类 agent 接不上外卖、订酒店订机票这些服务平台，**实际只能做看邮件**。
- **为什么看邮件有用**：邮件量很大，它真的能挑出重点、需要 prioritize 的，然后主动推给你——"这一点确实还挺有用"。
- **会不会收敛到一个**：最终会。现在试不同产品很大程度上只是尝鲜；**当生活中形成依赖之后，只要一个就够了。**

## 三、贯穿全场的五条主线（纵向归纳）

1. **被模型吃掉的都是"补丁"**：挑对的那次再封装 skill 的 pipeline、formal verification 提供的训练信号、外部 memory 架构——三者都是在"模型还不够强"前提下的工程代偿。模型一强，代偿全部失效。这是前四个 Aha 的共同结构，也是"要更相信 scaling"的实证基础。
2. **评价范式从"能力"转向"元能力"**：ApprenticeBench 测的不是答题，而是"边干边学"；long horizon 的定义从"一件事做多久"改成"从菜鸟到老员工"。伴随的是传统评价体系（论文、审稿、会议）的坍塌——**两者是同一个问题：静态打分测不出动态学习。**
3. **智力的定价在重估，落点是审美与情绪价值**：减肥药收入 > 模型公司收入、教授不如夜店男模、7 万块的短剧剧本变成一天 100 个——这条线在节目里被反复用不同素材砸实。谷雨的答案是"审美（定方向）+ 美（情绪价值）"。
4. **学术闭环 vs 市场闭环**：学术只要体系内自洽，创业必须和市场一起闭环。所以"taste 很好"的团队反而最容易变成 SPP——**taste 决定你能造多好的灭火器，市场决定别人已经卖了多少砖头。**
5. **组织的包袱变成了负资产**：大厂的 infra/recipe 从护城河变成"改不动的负债"，neo lab 的核心优势是"随时可以丢掉"。这是 RSI 这件事上创业公司唯一的结构性窗口——但前提是融到足够多的钱、卡、数据。

## 四、值得直接引用的金句

- "AI 现在的研发能力越来越强，总有一天它写 training infra、写 training recipe 的能力会超过人。那一天到来的时候，大模型公司之前积累下来的这些 infra 或者 recipe，反而可能会成为一种累赘。"
- "对大模型厂来说，那个东西有用，但为了用它需要适配 infra，代价太大，所以不愿意做。但对从 0 开始的 startup 来说，反正都是 AI 去搜一套新的 recipe，随时可以迭代它、随时可以丢掉它。"
- "真正的长程不是让一个会计把一份账报一个星期，而是让一个菜鸟员工变成这个公司的老员工——这几个月或者一两年的过程，才是真正的长程。"
- "做学术研究，你只要在一套技术体系内能闭环、能自洽就行。但做 startup 光自洽不行，光自洽是自娱自乐，你需要和 market 一起完成闭环。"
- "当一个人头上着火，他不会等着你给他一盆水或者一个灭火器，他手头有个砖头，他也得把头上的火给拍灭了。"
- "我们总想造出一个特别好的灭火器，但可能在你灭火器造出来之前，别人卖砖头的已经卖了 100 个。"
- "当你的智力不再值钱的时候，可能你的长相跟身材更值钱。"
- "想做一件事去做，就是一种理性；你想做不去做，我不知道这为什么算理性。"
- "大家都声明了这是 AI 做的，但大家也不 care 它是不是 AI 做的，大家 care 的已经是这个电影做得怎么样。"
- "未来人只需要两件事：一个是审美，一个是美。"

## 五、可直接延展的选题（内容侧）

1. **「被证伪清单」体例**：让 AI 从业者列"我今年判断错的事"，信息密度远高于列热点。这一期本身就是最好的样本——10 条里有 4 条是"我原来觉得不行"。
2. **RSI × 创新者窘境对照图**：左边"大厂：infra 是资产 → 改不动 → 不愿做"，右边"neo lab：无包袱 → AI 生成 recipe → 随时丢掉"，中间一条"研发能力超过人的临界点"。这是本期最可图卡化的一段。
3. **ApprenticeBench 的"流式 100 题"**：做成科普图卡——"为什么现在的 Agent benchmark 都测错了"，核心是"独立题 vs 连续题"、"答题能力 vs 元能力"两组对照。
4. **两种 long horizon**：一张图对比"任务时长轴"和"角色成长曲线"（菜鸟 → 老员工），这是本年最值得抄的概念转向。
5. **灭火器 vs 砖头**：学术团队创业的发布节奏模型，适合做创始人向内容——"发布标准过高是学术团队最大的隐性成本"。
6. **付费劳作观察**：拼豆自习室（几百种颜色 + 按小时收费 + 安静劳作）可以和第 1 期的《赵云与阿斗》串成同一条暗线——**AI 把效率推到极致之后，"低效但有人味"的消费在反向生长**。
7. **AI 电影实测**：以"观众是否还 care 它是 AI 做的"为切入，去 B 站找那部两小时僵尸片实测，弹幕反应本身就是最好的论据。
8. **Personal Agent 的两个设计点**：persistent 单一会话 + 拟人形象，可做产品拆解型内容（对比 ChatGPT/Claude 的 session 模型）。
