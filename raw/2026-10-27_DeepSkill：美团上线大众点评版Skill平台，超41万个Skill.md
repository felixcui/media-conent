## 产品介绍 🛠️

DeepSkill 是美团 AI 团队做的 AI Agent 技能平台，官方的定位是： **真测真评价，找到真好用技能** 。

![](https://mmbiz.qpic.cn/mmbiz_png/L3QFuGxENjet2iaNvia1roUictgyDWagkeGUSDGI7P1yGewgqCWlsYd7duAlshDlYIe7me6glIgrEPJWIA0Bd0dzGbpdc8jh2S2xalrFXsgrNk/640?wx_fmt=png&from=appmsg)

使用的时候直接在浏览器访问官网 www.deepskill.market ，不用注册，看到合适的就可以复制过去安装使用。

Chris 这边看了下整个站点的结构，主要分这么几块：

- **任务匹配** ：首页输入框，把完整需求丢进去，平台自动拆解任务、匹配候选 Skill
- **全部技能** ：37 万+ Skill 的总库
- **技能榜单** ：GitHub 趋势榜、权威来源榜、Market 热搜榜三个榜
- **技能点评** ：真实使用者的评分和任务记录，点评官招募中
- **技能实践** ：真实任务案例区

![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENje6RvbuDFufUhZliaAMkS3jM6sVIkxgYC3ah6XffaoN8qMUxZpahNicbIAUk9aX5brvlQBx78Tv50FE2kArYfsllLu0uE7tRP5R0/640?wx_fmt=png&from=appmsg)

在 DeepSkill 官方介绍里面，提到三个重要价值：

1. **找得全** ：覆盖 41.4万+ Skill，从热门通用工具到小众垂直能力，都能找到合适候选。
2. **选得准** ：把当前任务与 Skill 的历史实测任务逐一匹配，找出在相似任务上真正有效的 Skill。
3. **用得方向** ：每个推荐先过安全扫描，再检查真实任务效果，既避开风险，也避开“看起来会、实际不好用”。

这还是得体验下才知道真实效果怎么样。

## 核心功能 🌍

### 1\. 通过需求找 Skill

Chris 平时写公众号，排版检查这种重复劳动一直想交给 AI，正好拿这个需求来试试任务匹配。

这时候在首页输入框直接描述需求：

> 帮我找一个能检查公众号文章排版的 Skill，要求能识别标题层级混乱、段落过长、图片缺失的问题，最好能给出修改建议。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENjeJqiaP03LsME3VzCOIib4T3h1meKL6yGWtvz9wD1VaI5cICTR2BExHklAOgHsgBTJQM2kAicRAchcKSPFMZucVaLDqqef3YeLjac/640?wx_fmt=png&from=appmsg)

DeepSkill 接下来就会拆解任务，包括：

1. 理解任务需求
2. 召回候选技能
3. 安全与质量审查
4. 匹配最佳结果
![](https://mmbiz.qpic.cn/mmbiz_png/L3QFuGxENjemib1OQicVQLnQjRibXXbWLRhwIkpHkPABa2pcPEUlON9E7JwEictsLVyxnCWKtvicJpRP3UIhPAZ7vX7vt5EDB86gQjIVr1SazMAg/640?wx_fmt=png&from=appmsg)

任务完成之后，就可以看到智能推荐结果了，包含最佳匹配的 Skill：

![](https://mmbiz.qpic.cn/mmbiz_png/L3QFuGxENjfDgKSy4VTnjZuGAibDIVomcvxfGQkWnTtTf3naa8gABs5jUceP3PjHficvpFibkibXvHZZtjVysvIm04dz6Gnkjlb1icYNGjXdQBZQ/640?wx_fmt=png&from=appmsg)

接下来可以点击合适的 Skill，进入详情页。

这里就可以详细看到这个 Skill 的情况，比如这个 Skill 的描述与事实材料的相符程度、能做什么、如何工作等等。这对于我们去了解这个 Skill 还是挺有帮助的，至少提前知道适不适合自己的需求。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/L3QFuGxENjeeIT7wT2pROHK6SMZ2YtbZXoZcBJP4RyXOia9CPyH96KdWHTnzIagUIohU0wJibeNRqN1yseibzy2TPfLraPEzIWpIMXoNI7s7M4/640?wx_fmt=png&from=appmsg)

### 2\. 技能榜单

DeepSkill 还提供了三个质量比较高的 Skill 榜单，包括：

- **GitHub趋势榜** ：聚合 GitHub 上近30天最值得跟进的 Skills。
- **权威来源榜** ：汇集企业团队、高校院所与认证创作者 的公开 Skills
- **Market热搜榜** ：DeepSkill Market 汇聚全站用户搜索最多、下载最多的 Skills

**DeepSkill 不是一个常见的 Skill 商店，而是一套 Skill 的信任机制，像大众点评一样的 Skill 商店。**
