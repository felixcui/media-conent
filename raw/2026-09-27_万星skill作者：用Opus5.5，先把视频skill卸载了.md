GitHub 万星 skill video-shotcraft 的作者 Vincent 近日说：如果你在用 Opus 5.5，建议卸载所有用代码做视频的 skill。

他贴出的视频，由 Opus 5.5 一句话生成。所有部分都由代码完成，包括 BGM 和音效合成。

另一位网友 0xVibly 也用 Opus 5.5 做了个中秋短片，月亮、云朵、星星，氛围感很强：

有网友问 BGM 和音效是不是下载的付费素材，Vincent 说：都是代码合成的。还有人感叹，完全没用任何 skill 直出，效果居然比用 skill 还好。那一刻有点虚无，之前花大把时间打磨的视频 skill，全被新基座变成了无用功。以前觉得特定领域的 skill 是护城河，现在发现都是历史包袱。

笔者也尝试给tokenbank（一个可以管理AI资产并分享出租模型和智能体的开源项目）一句话生成了一个介绍视频，没有用任何的skill，不得不说对项目理解和能力呈现都很到位。

工具每跨一代，手艺的价值就从“怎么做”挪到“做什么”。当模型自己会写代码、会合成音乐、会把握节奏，中间那层“工具使用技巧”就薄了。

不过，这并不是说视频Skill无用，而是让门槛进一步下降，拥有一些SKill效果会更好，但注意的是，这类skill不应该是能力的束缚和封装，而更多的是灵感和方向的指引。也只有这样，才不会被下一代模型所覆盖而导致无用功。
