# agentusecases.ai：每天扫描全网的 AI Agent 真实用例库

**来源**: https://agentusecases.ai/

---

## 摘要

agentusecases.ai 是一个每天从开放网络、X、Reddit、Hacker News 扫描真实 AI Agent 用例的聚合站，目前已收录 1194 条用例，并按 11 类场景与 28 个 Agent 双向索引。每条用例包含一句话做法说明、所用 Agent、来源链接和「查看提示词」入口，另有每天早晨推送 5 条用例的邮件订阅、RSS 与投稿入口。

**功能**
- 每条用例可「View prompt / Share / Save」，支持收藏（Saved）

- 提供 RSS feed、投稿入口（Submit a use case）与赞助位
- 支持 Top / New / All / New this week 等浏览与 ⌘K 搜索
