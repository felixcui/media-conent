## 摘要

**DSH Go**：上周刚上线就火出圈的开源插件，把完整的 Agent 工具**直接装进手机**。两种用法：①**手机本机跑 DSH 引擎**——App 里一键搭好 Linux 运行环境，**不需要 Root**，授予**系统无障碍权限**后就能接管屏幕、点击滑动、操作各个 App，接近「豆包手机」的理想形态（自动订高铁票、跨平台比价等）；②当**客户端**，远程遥控你电脑或服务器上的 DSH。已知限制：微信页面读出来是空的（GitHub 上多人反馈）；从 **1.0.5** 起不再允许「看不清就盲点」，遇到这种页面会停下。安装时可选引擎装本机还是远程主机。

## 实测案例

WorkBuddy 或者 Codex 我们都很熟了，虽然有手机 App，但真正执行的任务的还是你电脑里的 Agent 工具，还得在电脑环境里干活。

而 DSH Go 是把一个完整的 Agent 工具直接塞进了手机里，让它直接在手机上跑系统级的自动化操作。

它主要能干两件事：

第一，手机本机直接跑 DSH 引擎，在 App 里一键把 Linux 运行环境搭好，不需要 Root，给它开了系统的无障碍权限，它就能帮你接管屏幕、点击滑动，去操作手机上的各个应用，通俗点说，就是类似豆包手机的玩法。

第二，可以作为客户端，去遥控你电脑或者远程服务器上的 DSH。

单看第一个玩法，我就已经忍不住了，立马安装下载装好，断断续续深度玩了一个星期，前前后后给它派了不少活儿。

先来看一段视频，这是我让它去帮我订了一张高铁票。

怎么样，是不是很舒服？我当时就给它发了一句话，把车次要求交代清楚，顺便特意补了一句：付款的时候叫我。

视频中间有加速，但是整个任务也就是跑了两分钟，找到了对应的车次，再选择乘车人的时候，因为他了解我的身份信息，所以自动就帮我选中了我的信息。

你看，就像这种卡点，如果你不给它提供足够的上下文，那它就会卡住等你来点。

如果你喂足上下文，那就只用等着订单锁定去付款就行了，当然，如果你也不想点，也可以让他去帮你付款，但是我建议还是稳重点儿好。

顺手我又测了几个其他场景，先看一个高频场景，让他去不同平台比价格，最近是想入手一个 3D 打印机，我就让它去搜搜看。

这是让它去京东、淘宝和拼多多三家官方店做横向比价。平时我们自己动手查，最头疼的就是各家平台的套路，什么会员专享价、百亿补贴，还有叠加国补这种藏得很深的优惠。

它跑完之后把这些附加条件都算进去了，最后给出一张干干净净的对比结果，哪家实际到手最便宜一眼就能看出来，比自己一家家翻省心太多。

再来一个，手机里边有些 APP 用起来门槛挺高，就比如这种广告屏蔽规则的，很多时候我们也只能是去用现成的脚本，但是现在就不一样了。

你可以只管说出你的需求，剩下的交给 Agent 去帮你跑。

我让它打开 AdGuard，把里边所有能开的屏蔽规则全给打开。

它干活很利落，能开的都顺手打开了，碰上需要安装根证书的 HTTPS 过滤环节，老老实实停下来交给我手动确认。

遇到需要 Root 权限的防火墙选项，也保持关闭没乱动，最后还列了一份清单交代哪些开了、哪些没动，让人很放心。

关键是，这些活儿如果他不帮我干，大部分用户估计是真懒得去挨个查，挨个点。

最后再来一个我觉得最爽的，还是之前的老问题，就是微信公众平台会把几年前的旧文章翻出来，给你判个违规，就很烦。出于安全考虑，前阵子我也让 AI 去帮我扒拉了一遍可能会有风险的文章，列了个清单。

但是后来我才发现，在微信公众平台上，网页端每次删文章都得扫码确认一下，那实在是太麻烦了，订阅号助手里边就可以，不需要扫码，直接删文就行。

所以我立马就想到，总算可以把这个活儿批量完成了。

而且我只给他说了一个大概的需求，能看视频就知道这个需求其实很模糊。

我只说了可能敏感有风险的文章，然后他自己就去想了几个关键词，去挨个排查了一遍。

如果是那种愣头愣脑的脚本，可能上来就乱砍一气。但它挺克制，先把符合条件的 9 篇候选文章列出来让我挑，然后我就定下来：把 234568 都删掉。

它立马就去删得干干净净，没勾的完好无损。

特别是在折叠屏手机上，你在这边刷着红果，他在那边一通忙活，我只能说，真的，太舒服了，太爽了。

到这里，我知道大家肯定还想问一个问题：微信呢？

答案是，微信确实用不了。

我实测下来，微信界面截屏之后，它读取不到页面上的节点，也就是不知道按钮和文字都在哪，这一块等于被微信给限制了。

去 GitHub 上翻了翻，好几个人也反馈微信页面读出来是空的，加上 DSH Go 从 1.0.5 起不允许看不清就盲点，到这一步只能停下。

官方文档里也专门提醒过，微信这类 App 有风控，曾有手机助手操作后账号被强制下线，所以默认给微信设的是每一步都确认。

微信永远还是最特殊的那一个。

## 上手配置

接下来给大家简单理一遍，使用时候的设置，其实也没有什么特别难的地方，跟着引导一步一步操作就行了，作者在交互上下了功夫，基本都做成了点选操作。

下载：github.com/ccch1mneyyy/dsh-Go/releases

平时大家手里的主力机型直接选 arm64 架构的安装包就行，系统要求只要是 Android 8 及以上都能跑。

![安装好之后](https://mmbiz.qpic.cn/mmbiz_png/4QK9bGpA4N86VqlNHvgUZmiaGia27UmnkApibf77VEQtJvia03tvGyA7XAE29iaojeib9jictheVZeAAYp6ft5MNq8edjgm3icfjsLpc1G5qFpfFQRk/640?from=appmsg)

安装好之后

装好之后桌面上就多了个 DSH Go 的图标。第一次打开应用的时候，它会让你选把 DSH 引擎安在本机还是远程主机。

选本机的话，它会在 App 内部直接把一整套独立的 Linux 运行环境布好，界面上会标明具体需要的存储和内存空间，完全不需要 Root 权限；要是手头机器配置吃紧，走远程模式会更合适。

我们就先介绍本机安装设置。

装完进入主界面，在设置 › 本机引擎里，有的版本放在设置 › 主机 › 本机引擎，默认已经勾上了打开 App 时自动启动和自动进入安全模式。

平时不用管它，要是哪天不小心折腾崩溃了，它连续启动失败两次就会自动掐断插件加载，方便你排查问题。

本机引擎和模型渠道

在设置 › 模型里分成了官方、订阅、自定义三类。对我来说最省心的就是走官方的 DeepSeek 渠道。

点进去直接支持用 DeepSeek 官方账号登录，会在浏览器拉起授权，只要本机引擎跑着就能顺利绑定，连填 API Key 的功夫都省了，调用费用直接从账号余额里扣。当然如果你手里有现成的 Key，随时填进去替换也行。

点进确认方式，有三档可以选：

默认的是每次都询问，一旦进到新应用，或者遇到发送、删除、付款这类敏感节点，它一定会弹卡片先请示你；第二档是本任务免确认，同一个任务里只要点过一次允许，后面就不再反复弹窗打扰；最后一档则是完全放手的始终免确认。

新手建议保持默认的每次都询问，我估计你用不了多久，马上就会无脑确认，这个操作反正大家掂量着来就行。

应用名单里的限制更细，出厂默认就已经把银行、券商这类涉及真金白银的 App 划进了不碰名单。

像微信这种高频通讯软件，默认也被设定为每一步都确认，我截图里这台把微信改成了照常这一档，但实际上用起来，微信是没有办法完全自动化的。

至于更底层的解除限制板块，涉及系统设置、密码验证码输入、以及 DSH Go 自身界面的操作，这三项在出厂时全是死死关着的。

真想开启某一项，还得长按确认按钮大约 1.5 秒才会生效。一句话，牵扯到账户密码和核心资产的边界，老老实实留给自己掌控。

另外，对进阶玩家来说还可以配合安卓玩机党的老牌搞机软件 shizuku 实现在后台免打扰操作，这部分，供学有余力的同学进一步往下再摸索。

远程主机和工作区

你就可以在手机上远程指挥电脑上的 DeepSeek harness 干活了，这个就是传统远控 Agent 操作，大家就很熟悉了。

要是想用回手机本地的 DSH，再切回本机就行。发指令前记得看一眼顶部的主机和工作区状态，别把发给手机的活儿误派到电脑上。

对了，现在这个项目还仅仅只支持安卓，用苹果和华为手机的小伙伴肯定得问：什么时候出 iOS 和鸿蒙？

我翻了翻作者的动态，10 月 30 日 Star 破千时就表态要适配这两端，让大家敬请期待，只不过作者也没想到当天就破千了，属实热度太高了。

## 结语

折腾了这么整整一个星期，DSH Go 给我最大的感触，就是那种久违的极客作品该有的灵气。

以前我们用 Agent，总觉得它只能待在电脑里。现在，Agent 也能在手机里面跑起来了，也能直接接管日常琐事，把人从机械点击里解放出来。

在大厂的 AI 手机还在步履艰难一步步摸索的时候，一个个人开发者凭借着一套扎实、干净的开源架构，硬生生把一个能跑在口袋里的 Agent 实实在在地交到了普通用户手里。

工具说到底还是为人服务的，能让普通人低门槛用上，并且提升效率，本身就是一件很酷的事。

我们真正想要的那种豆包手机目前看来还遥遥无期，但是如果你手头刚好有一台闲置的安卓机，或者平时就喜欢在手机上折腾自动化工作流，这个项目绝对值得第一时间装上试试。
