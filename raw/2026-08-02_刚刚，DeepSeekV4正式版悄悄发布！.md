## 三、官方支持接入Codex，保姆教程来了

## DeepSeek-V4-Flash 正式版原生支持 Responses API 格式，针对 Codex 做了适配。

## 第一步：备份现有配置（可选）

一键脚本自己会备份到 ~/.codex/backup-deepseek/，但只留一份，重复运行会被覆盖。手动做一份带时间戳的更稳妥，尤其是你的 config.toml 里已经配了 MCP server 或项目信任级别的时候。

macOS / Linux：

```bash
cp ~/.codex/config.toml ~/.codex/config.toml.bak.$(date +%Y%m%d-%H%M%S)
```

Windows PowerShell：

```powershell
Copy-Item $HOME\.codex\config.toml "$HOME\.codex\config.toml.bak.$(Get-Date -Format yyyyMMdd-HHmmss)"
```

提示文件不存在就说明你还没有配置文件，跳过即可，脚本会新建。

## 第二步：跑一键脚本

macOS / Linux：

```javascript
bash <(curl -fsSL https://cdn.deepseek.com/api-docs/codex-deepseek-setup-en.sh)
```

Windows PowerShell：

```nginx
irm https://cdn.deepseek.com/api-docs/codex-deepseek-setup-en.ps1 | iex
```

菜单里选 deepseek-v4-flash，首次运行会要求填 sk- 开头的 API Key，去 https://platform.deepseek.com/ 拿。

脚本会自动备份原配置、写入模型目录 ~/.codex/models.json、只改 config.toml 的必要字段（保留你原有的 MCP server 等设置）、写入前先校验语法，校验失败会中止且不动任何文件。

## 启动横幅显示 model: deepseek-v4-flash 就成了。

![Image](https://mmbiz.qpic.cn/sz_mmbiz_png/zW6S9vt0cSic2NY5NRhNjSLM2biaN1KCr8dDH7zNP8HaHtv0zEHSrtjPzYecfOoqKqTmktKGAc0xiaUEnT9iaHfeZJdOB28OXUPiapUnZPheuN0A/640?wx_fmt=png&from=appmsg)

横幅上模型名后面跟的是推理档位（图中为 xhigh），由 config.toml 里的 model\_reasoning\_effort 决定。接 DeepSeek 官方 API 时这个值只能填 low、high、max 三档之一，没有 medium，也没有 xhigh。

如果横幅里没有 model 这一行，检查是不是在改配置之前就已经启动的旧会话——Codex 只在启动时读配置，改完必须新开终端。

ChatGPT 桌面端的模型选择器会显示 Custom，这是正常的——桌面端把所有本地配置的模型都显示成 Custom，实际跑的是 DeepSeek 模型。VS Code 插件与 CLI 共享配置，装上直接用。

## 回滚

重新运行脚本选菜单选项 3，恢复到安装前状态。或者用第一步的备份手动还原

```bash
# macOS / Linux，文件名换成你的实际备份cp ~/.codex/config.toml.bak.20260731-180000 ~/.codex/config.toml
```

API Key 是明文存在 ~/.codex/config.toml 里的，不要提交到 Git，也不要在截图、录屏、分享配置时带出去。
