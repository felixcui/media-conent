## 摘要

文章以量化交易小白的视角，分享借助AI编程工具「豆包工作」搭建量化策略的入门教程。作者先在本地创建'quant'文件夹并导入豆包工作新建项目，随后注册Tushare数据平台获取TOKEN（建议2000积分以上档位，年费约200元）并写入.env文件备用，最后在豆包工作连接器中搜索安装Tushare并完成官网授权，从而跑通选股、回测和提醒的量化流程，并声明内容不构成任何交易建议。

步骤如下：

1\. 在你习惯放代码项目的本地目录内创建一个文件夹，我这里是一个叫‘quant’的文件夹

> 当然，你也可以直接在Github上创建仓库，同步到本地

2\. 打开「豆包工作」，点击项目的‘+’按钮

点击右上角头像-->个人中心：

> 建议获取2000积分以上档位，一年¥200足够用了；

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/0m9F5vC1OGjL1IkOMbvvGOB9DjbHEdp5g9Y0HgpGNDFk1l4X4JxvIW063W4Edh9l43TTLtaVqQ1tZMWCeUaaTfOouXDFL63LtYUXoic2JSQU/640?from=appmsg)

6\. 策略制定

> 注意：这里的策略是个非常“for example-仅为示例”的例子，不是让你直接拿过去就用哈～

```
现在，让我们尝试制定一些量化交易的简单策略 请找出当前 A 股市场中符合以下条件的所有股票：
1. 基本面良好
2. 市值超过 300 亿，流动性良好
3. 技术指标层面处于深度超卖
```

豆包会根据你输入的策略，从TUSHARE连接器拉取数据

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/0m9F5vC1OGiaqJJ006xWCCUhgLN5BSJiargDTwhX3ht0TWWNkF8prF13rTxibTR0vTBgCAEr3nFGoaAu0yFB0aIH82Cp8iakYFowIHgOwicZrv4E/640?from=appmsg)

![image](https://mmbiz.qpic.cn/mmbiz_png/0m9F5vC1OGhko4HFxpQRu2dUW9s8lDbVMZM7D0gXAPX6v5ZuJsvDxDpptzXwlzrGPS46h5SNkSjTp0csGVlicLT69vj3hkxjKmTwekv7x7hE/640?from=appmsg)

然后要求豆包：

```
请设计交易策略并进行回测
```

跑了十来分钟后，豆包会生成一个交易策略并给出经过回测后的策略报告：

![image](https://mmbiz.qpic.cn/mmbiz_png/0m9F5vC1OGhknrdsMMW5TsgnYnypdJof4oFoSyLQQicT4hJfxiaicYPnVpUWbPA6sF0b3lWvvLmiaCeTxg4VU7CAQqkJJkRO3q0P25ALRpagOzE/640?from=appmsg)

然后询问豆包：

```
在选中的股票池中是否存在符合交易策略的标的存在？
```

它会给出相应的股票选择：

![image](https://mmbiz.qpic.cn/mmbiz_png/0m9F5vC1OGjVukpb0zziaqYpDp9fql8RcX9dyKAGtfXMdcIqNKPwD02Zj7v0Nic28yq5V0lJAVMnn3LknRkia3ZO7rWlx7TaD9SUEjzNHHZibxM/640?from=appmsg)

7\. 将消息同步到飞书

```
请在每天开盘和收盘时将符合交易条件的股票（名称、代码及交易条件）推送到我自己的飞书消息中
```

豆包会创建2个cron job（定时任务），然后将消息推送到飞书中：

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/0m9F5vC1OGggt84sR84afOibWAkf2oC3b4LEBVyoRNmSgL5q9EZHN1O1MVsaIxm0KVeyDdaNAbPAiamibExQb1zZLIGeZ13IicLOF6vFUvdOJ6g/640?from=appmsg)

OK，到这里，基建就基本建设完毕了～

中间需要调整的是具体的量化策略本身...选择什么因子来筛选股票池，回测，以及交易时点的确认～
