# Opus 5.5 做视频全教程：一段话到成片，16 种风格 Skill 免费开源

**作者**: 成峰

**来源**: https://mp.weixin.qq.com/s/1e3Y0n7R7vsjVTO-Fs3e7Q

---

## 摘要

作者开源了基于 Opus 5.5 的视频制作 Skill「chengfeng-video-styles」，内含 16 种现成风格，用户只需安装该 Skill、输入一段内容或主题，即可让 Agent 先跑 3 秒样片挑选风格，满意后再生成全片，还可拖入参考视频让模型逐帧复刻新风格，实现从一段话到成片的自动化视频生产流程。

我最近做的视频，全是用 Opus 5.5 做的，效果我也很满意。

![](https://mmbiz.qpic.cn/mmbiz_png/7e6H2Zjkupzep7ic2QcriaFG4QCcROxpmnExLXhlv9nlzOrjDzNRFKKqgzyYyticicRkTSgeohMUJjME1otwbeVQeR7jA8YM81oxAY3q6lce3mw/640?wx_fmt=png&from=appmsg)

这次，我把这整套做法打包成了一个 Skill，叫 chengfeng-video-styles，免费开源。

其他模型也可以用，但是效果相对会差一些。

**1\. 让 Agent 安装视频风格 Skill**

打开 Agent，发给它这个提示词：

帮我安装视频风格 Skill：chengfeng-video-styles  
  
安装命令：npx -y github:Agentchengfeng/chengfeng-video-styles install

![](https://mmbiz.qpic.cn/sz_mmbiz_png/7e6H2Zjkupx9eC9207ibpNQOu9KCVLORfeOwPpYVZBVc2f7MicfQiaIOjnWnLqIlicCZ8QGNqmUSWEqpjyZEuhKficTxCVQAYs1CfQu07aib7hmns/640?wx_fmt=png&from=appmsg)

装好后，新开一个 Agent 会话，Skill 才会出现。

**2\. 把你自己的内容交给它**

发 /chengfeng-video-styles，后面接你想讲的内容。一篇文章、一个概念都可以，只要给一个信息就行。

比如我给的是一个主题：

/chengfeng-video-styles  
以前，视频生产围绕时间线展开。  
现在，视频生产开始围绕工作流展开。  
剪辑 Agent 正在替代传统剪辑里的操作层，把视频生产变成一条可以持续复用的自动化流程。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/7e6H2ZjkupwSrrKp2lwRibFpryuv7jvLNoTozgZxYrD8BiaH6m0T3NHz52Beic6bdtoibdgE5jREycTKYqgm7R6tWTv3zfhSoFubagVrZvThTQQ/640?wx_fmt=png&from=appmsg)

**3\. 定参考**

Skill 里有 16 种现成风格，都来自我自己做过的片子。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/7e6H2ZjkupzhBKtcA0hJRmR2bkwZlSPToxGZCoXeqGXUueOE4zGWB6wgfV9yBiaF4JNrx6qibpp3Wd9pvkibbibJuZRNLmuqO6nuN18fh6r6WbY/640?wx_fmt=png&from=appmsg)

想加别的风格，把你觉得最好的那条视频或者图片一起发给它。Opus 5.5 会逐帧去看：每一段多长，镜头怎么动，怎么转场，然后照着做。

我手上有一条纸艺风格的视频，不在 16 种里，就在内容后面拖入视频，说：

**4\. 先看 3 秒样片，挑一个**

这里很关键的一点是，我们不要一下子就把一个视频全部做完。

先跑一个样片，满意了，再做全片。不然整条片子跑完，额度也用完了，效果却不满意。

接到内容后，它先做了 17 个 3 秒样片：16 种风格各一个，第 17 个照纸艺参考做。每个只做这段话里最出彩的那一拍：从时间线到工作流。

![](https://mmbiz.qpic.cn/mmbiz_png/7e6H2ZjkupxsoibHSRPtPXicbiamRZ1bs5SPnTdicEIvLrdfowfbkxOeZrLmxQf0ymB7UV8YGPjLib9A8AWgFUVEibJ3Xrk7xUvpAaicHBWxTsiaIpk/640?wx_fmt=png&from=appmsg)

做完放进一个网页里，它会自己在浏览器里打开：

![](https://mmbiz.qpic.cn/mmbiz_gif/7e6H2ZjkupxTQ0KvoJNQcvaNwHia23Ys8p1ib2OgHrxQ1vbrRvxO4qyPaDP0TO79C7e5gNjqaS5wPzasvKAnUr2ockqjXM1XPnzaW6DA2dHibg/640?wx_fmt=gif&from=appmsg)

没弹出来的话，在你打开 Agent 的那个文件夹里找 样片筛选.html，双击打开。

**5\. 出全片**

你对哪个风格满意，就可以告诉 Agent，比如我选了 17，照纸艺参考做的那个。它照着 17 把 全篇做完。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/7e6H2ZjkupwwaYozGYNUaEgwQwNKgFf9Vo8YzJRHJzXlYFh8bQqgw2ibalAqTmloxCC2mexm2T8ohvRCcSeezfktfJAZHpsQkpc7ibpqAB0x0/640?wx_fmt=png&from=appmsg) ![](https://mmbiz.qpic.cn/mmbiz_gif/7e6H2ZjkupxhDyn4mE2sTdmvO9lGvBUeuibUCmRZAtcuUFIj0GOicQAcv7JqneibMibeRx8uFX1DHibqGahr61z7JLsicObAaUEKIibKZjPu0sVdTQ/640?wx_fmt=gif&from=appmsg)

做出来是一个 HTML 文件，它做完会告诉你放在哪，浏览器打开就循环播放。

**6\. 导出 MP4**

要发到视频平台的是 MP4。它没自己导的话，跟它说：

导出成 MP4

![](https://mmbiz.qpic.cn/sz_mmbiz_png/7e6H2ZjkupyE9L9TmJ5eHXMbcgs0vpCsHQs1mHkncp627r4PJ7nycgDtlnF8jPWCMCkqlIiaBc8xNP96sSlA6T90k3IOj9tv8MPzwYAAPez8/640?wx_fmt=png&from=appmsg)

我试了一次，4 分半左右导完。

**7\. 加音效和字幕**

想加声音和字幕，跟它说：

加上音效和字幕

![](https://mmbiz.qpic.cn/sz_mmbiz_png/7e6H2ZjkupxwoTuLF1pxSlFVy1GibKZhBmXviaukfZ80ibucXLEWuDjRDeyHoBqchmsusuY0jAepGlmHwicv8RRpuibEEiaBWgouCr4Sc4bWcH6us/640?wx_fmt=png&from=appmsg)

不用准备素材，音效它用代码合成。我试了一次，20 分钟左右做完，它自己重新导了一份带声音和字幕的 MP4：

它自己听不到声音。你听一遍，哪一秒不对，告诉它是第几秒，它单独调。

到这里，一个视频就做完了。
