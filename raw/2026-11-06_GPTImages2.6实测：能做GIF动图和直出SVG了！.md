# GPT Images 2.6 实测：能做GIF动图和直出SVG了！

**作者**: AI范儿

**来源**: https://mp.weixin.qq.com/s/x0msPFiPF54fzpaqnljdIw

## 摘要

OpenAI发布GPT Images 2.6，新增GIF动图生成、SVG直出和生图提速等功能。实测显示，模型能根据提示生成精灵图并拼成循环GIF，在蝴蝶翅膀与投影联动、香水瓶标签一致性等任务中表现较好，但在人物握伞关系、手部细节和背景稳定性上仍有明显瑕疵，适合制作趣味动图但尚不足以直接用于精确商业场景。

从 GPT Images 2.0 开始，GPT 就一直是我唯一使用的画图工具。

对我来说，它的质量无与伦比。Nano Banana Pro 之类的，我都没再用了。它似乎已经退出比赛了，至少在我的日常使用里是这样。

两个月前，Images 2.5 加强了主体一致性和多轮编辑，也改善了细节、复杂布局和速度。

Sketch 草图、模板、图片评论和提示词分享，也是在那次加进来的。我当时写过实测，放在文末了。

现在，Images 2.6 又来了。这次先看一个新东西：GIF。

▲ 视频：官方 GIF 案例合集

比如这只玻璃蝴蝶，翅膀展开，地上的彩色影子也跟着展开。直接告诉 ChatGPT 想要什么画面、怎么动，它就能生成 GIF。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/8TRTn7cvcJKexlyqMIpjujDtBFwUZAqfZ84BybDKsNq3yyB7HIgUqiarDTE82p9tA5pdNAGibLBeZU5zz1u91epkDJ00Qiause0icK0ln9iaLAeM/640?from=appmsg)

▲ 图：玻璃蝴蝶与翼影

OpenAI 在 11 月 4 日发布了 Images 2.6，已在 ChatGPT、Codex 和 API 上线。除了 GIF，还有 SVG、生图提速，以及编辑方面的改进。

这次让 Agent 在 ChatGPT 网页里做了四组测试。下面都是实际返回的 GIF，没补帧、没修字，也没交给其他视频模型重做。SVG 等功能则看官方案例。

## 一张图，怎么变成 GIF？

先看 OpenAI 的介绍，已经加上中英双语字幕。

▲ 视频：官方演示与双语字幕

官方说得很直接：先生成精灵图，再把每一帧拆出来，拼成循环 GIF。

精灵图就是把连续动作画在同一张大图里，每一格一种姿势。按顺序播放，画面就动起来了。

所以，单张好看还不够。前后几格里的脸、手和物体，都得接得上。

## 翅膀动了，影子也得跟上

开头的蝴蝶，要求是蓝绿紫的玻璃翅膀、金色叶脉，停在玫瑰金枝条上。镜头固定，翅膀展开、合拢，再回到原位。

结果里，翅膀和投影都动了，透光感也还在。这个彩色版是在灰白版基础上调整过的，没有只抽一张最好看的帧来展示。

不过，放慢看，细纹还会变，两侧翅膀收拢的节奏也不完全一致。做一张有意思的循环动图可以，别把它当成准确的生物运动。

## 商品转起来，标签还在吗？

再试一瓶虚构的 SOL 香水。琥珀色玻璃瓶、青绿瓶盖，悬在水面上，后面绕一条橘子皮。

要求瓶子小幅左右转动，水波和反光跟着变，标签上的 SOL 不能变。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/8TRTn7cvcJJ3gyFyZv1hT2qET0BjDTqcjLtFnTvtdf12bqYeriadzLtmYCW6gicVgsZZmCq3n9x6xv7ibw28eGyYD95Cp02oMKZbKpjZaETkR8/640?from=appmsg)

▲ 图：香水广告循环动画

16 帧里，SOL 一直能认出来，瓶子也没有变成另一件商品。玻璃的厚度、水面的反光，放在一起挺有广告的感觉。

但瓶身边缘会变一点，背景的叶子和橘皮也没完全固定。真要用自己的商品做广告，包装细节还是得一帧帧看。

## 摸狗的动作有了，伞却出了问题

这次加一点情节：女孩撑着伞，蹲下来摸柴犬的头。狗歪头、眨眼，耳朵随着抚摸轻轻压低。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/8TRTn7cvcJLuhvhSL8jAAWvUZBfqgibOZUwQvrcmzntHTr7iaq7OqgE7TvRUd67L2768muLEvTXDC4697NLVwG0wxx9RNfR5JtBaMrl65RTrU/640?from=appmsg)

▲ 图：雨夜抚摸柴犬

抬手、碰到狗、闭眼、收回，这个顺序能看出来。黄色雨衣、砖红围巾，加上雨夜的灯光，画面也比较舒服。

问题在另一只手。要求它一直握着伞柄，结果那只手基本放在膝盖附近。伞到底怎么撑住的，没交代清楚。

手、狗脸的细节也会变。动作看起来成立，不代表画面里的每个关系都对。

## 瀑布流起来了，但没按要求出图

最后换成峡谷瀑布。固定镜头，让水往下流、水雾翻动、潭面起涟漪，前面的蕨叶轻轻摆动。

![](https://mmbiz.qpic.cn/sz_mmbiz_gif/8TRTn7cvcJKR9EfqMItLx6DF3ibXmbnlAFcQcscRLKMs8e53cW4b5Pjh0Qo0pfOyJVjHXmBBLiclFtpqLcsC1h1IibcEZwMaYykPQnSa7ek63o/640?from=appmsg)

▲ 图：峡谷瀑布循环动画

水流、水雾和波纹都有变化，色彩也比较饱满。但细看会发现，原本不该动的岩壁和花叶，也被重新画了一点。

还有个更直接的问题：要求 16 帧、横版 4:3，实际给了 12 帧、358×358 的方图。每帧 160 毫秒倒是照做了。

所以，提示词写了什么，不代表它最后一定按那个规格交。

## GIF 到底能做多大？

**官方有明确的尺寸规则，不是只能做三百多像素。**

API 可以填 `auto` ，让它自己选；也可以指定宽和高。 `size` 指的是 GIF 每一帧的像素尺寸，不是整张精灵图的尺寸。

自定义宽、高都要是 16 的倍数。官方提示词指南还要求，自定义画幅的宽高比在 1:3 到 3:1 之间。

更具体的例子也有： **官方用 Sunburst 生成了 512×512、9 帧、每帧 200 毫秒的 GIF，一轮 1.8 秒。** 下载官方样例后，文件规格也确实如此。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8TRTn7cvcJJIn7o8rsWABwLS7bw70a8tLsZRr2xlAHj4hsHaNs8Scbp3sRrAPGKzaHyIaGHtqLLxC15CjrQzcicZpfGx4LBX8VkfIN1iaqny0/640?from=appmsg)

▲ 图：官方 GIF 规则与实测尺寸

要注意，尺寸、帧数、一次生成几张动画，还得一起满足总像素预算。超了就要减帧、缩小画面或少生成几张；官方 GIF 小节没有给出这个预算的具体数值。

这次网页返回的小图，只能代表这几次结果，不能拿来当模型上限。反过来，也不能把静态图的 4K 直接算到 GIF 头上。

GIF 没有声音。十几帧拼成两秒左右的动作，会有逐帧动画的感觉；能循环播放，也不保证首尾完全接得上。

## SVG 又是什么？

GIF 是让画面动起来，SVG 则方便把图继续拿去改。

PNG、JPG 存的是像素，放大容易糊。SVG 记的是线条、形状和颜色，放大还能保持清晰，也方便改颜色、调形状。

下面是 OpenAI 给同一家面包店做的两个官方例子，分别来自 Flare 和 Sunburst。

![](https://mmbiz.qpic.cn/mmbiz_png/8TRTn7cvcJI7JRLaYDsYqvwPTGM3E1pBn0HfjnVYRXrwYDFWiaWYIGSiadyxYVibcPpHAcVUv1urDALh0roe9ny5fhFtdCDfy4esaGqBoNP628/640?from=appmsg)

▲ 图：官方 SVG 标志案例

文章里展示的是 SVG 渲染后的图，原文件是矢量内容。Logo、图标、插画这类要适配不同尺寸的东西，就适合用它。

但它不会把任何照片变成 Photoshop 分层文件。官方的做法是先生成参考图，再生成 SVG。 **这次输出的是静态 SVG，不是 SVG 动画。**

## 其他更新，简单说几件

速度方面，OpenAI 称生图比此前快 50%；Flare 在低质量设置下，最快六秒出图。

两个 API 版本各有侧重：Flare 偏速度，也改善了海报、产品图的排版；Sunburst 在中高质量设置下，更看重细节，以及多改几轮之后能不能保持原样。

标注编辑这次也进了 API。把要改的地方圈出来，再告诉它怎么改。官方例子是把厨房里的花瓶改成蓝色。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/8TRTn7cvcJJAJD3kZsxIuEAWzibpZsE9bafgicxjz6SsWky4C06spQ5urH2zdyAPJKgm8HC7NlqQm5tFRnSCOB89AgWPLSEXIrALm3tTdickCQ/640?from=appmsg)

▲ 图：官方圈选编辑示例

还有个 `complexity` 参数，可以理解成让模型动笔前多想一点，还是少想一点。它和控制画面细节的 `quality` 不是一回事。

官方用同一条足球夺冠提示词展示不同档位，球衣、奖杯和文字位置都有变化。

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/8TRTn7cvcJIVKnCBzurxZc9licGsicxoep0p6brHbH8eSy4Xrb3IoljDSNq3AwHR0NvHAjGrfto5c8WcsFn0F72FmDF8ZO4sPs470zhdpMLWQ/640?from=appmsg)

▲ 图：官方复杂度档位案例

不是越高就越好。官方提醒，高复杂度可能更慢，也可能多改一些你没让它改的东西；一般局部编辑，推荐从低复杂度开始。

开发者接入时，GIF 和 SVG 都通过图像生成接口选择输出格式，编辑接口目前不能直接输出这两种格式。

## 最后说几句

![](https://mmbiz.qpic.cn/sz_mmbiz_png/8TRTn7cvcJKwvLpIvV5b1vFwUxGibS4kqchwbprS6Rq759iahib50eEchxuCexLGNWEZnA5JVMCpgBsXZ0oDtGOvlqU6cwmGkInopqYicOL3LmU/640?from=appmsg)

▲ 图：ChatGPT 的 GIF 新功能入口

ChatGPT 各入口已经开始使用这些新的功能了，快去体验吧。

这个世界缺不了动图。每天聊天用的表情包，网页、公众号里的演示，我们其实一直在看，也一直在用。

但这几年聊 AI，大家更多是在比静态图画得好不好，或者视频做得真不真。夹在两者之间的动图，好像没那么受关注。

这次 OpenAI 把 GIF 直接放进了生图工具里。一张图除了能画出来，还能接着动起来。我相信，这会打开一个新的创作空间。

AI 发展到今天，能力越来越强，我们能做的事情也越来越多。以前觉得门槛很高的动图，甚至视频，现在一句提示词就能开始做。

工具是强大了。那么真正需要我们补上的，也许是自己的审美和创意。
