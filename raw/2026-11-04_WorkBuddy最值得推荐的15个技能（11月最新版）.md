## 摘要

程序员小灰的 WorkBuddy 技能月榜（11 月版）共 15 个，分四类。信息与学习：**Agent Reach**（让 Agent 检索 B 站等平台公开内容并整理成表）、**Summarize**（长文压成中文要点+对照表的 Markdown 报告）、**Academic Research Skills**（论文选题→结构→文献检索）。思维与决策：**Bloom**（一对一 AI 私教）、**魔鬼代言人**（先让别人挑毛病）、**白毛股神 Serenity**（整理投资研究问题）、**cc-thinking-skills**（提前推演计划会怎么失败）。创作与演示：**YouTube Clipper**（从长视频里挑完整片段）、**宝玉设计**（把阅读器想法做成可操作原型）、**GSAP 官方技能**（网页动画）、**HyperFrames**（网页动画渲染成视频）。商业与副业：**dbskill**（商业问题拆成可验证步骤）、**企业调研**（公司信息与证据放一起）、**Wondelai**（产品想法→访谈问题）、**marketingskills**（首封邮件与后续回复）。每个都给了 GitHub 地址与一句话安装方式，文中详细实测了 Agent Reach 与 Summarize 两个。

## 一、信息获取与学习

## 1、Agent Reach：检索并整理平台公开内容

你平常有没有遇到这样的问题：想让 AI 帮你看看 B 站最近有什么值得关注的视频，它却说访问不了？最后还是得自己搜关键词，再一个个点开看。

**Agent Reach** 主要解决的就是这类信息获取问题。它把不同平台的访问工具接入 AI，让 WorkBuddy 能搜索、读取公开内容，再整理成你要的摘要或清单。

小灰这次选了 B 站来测。安装后让 WorkBuddy 补齐 B 站工具和技能入口，已能在安装列表搜索确认。

装好后，小灰发了下面这句提示词：

```
检查 B 站近期关于 AI 大模型最新进展的热门视频
```

它先检查访问工具，再用「AI 大模型」「大模型发布」「AI 日报」等关键词搜索，但需要注意的是，B 站部分字幕需要登录才能获取，所以这个技能只负责找。要看懂具体内容，可以再点开原片，或者接 Summarize、YouTube Clipper 这类技能做下一步。

![](https://mmbiz.qpic.cn/mmbiz_png/vsAViaKGWic0UwCFS3XcDRpefxMYaDiaUGErjX5bQASOOHr3uqibyUQedgC17GVrUIHh4PAFxXbr7IcAnpSTUyzpLfnHSftWAwiboibpJ7uRczoOI/640?from=appmsg#imgIndex=0)

## 2、Summarize：先把长文章读薄

你平常有没有遇到这样的问题：收藏了一篇长文章，知道它值得看，却一直没空读完？

**Summarize** 可以提取网页和媒体内容，交给 WorkBuddy 整理要点。小灰选了 Anthropic 的《Building effective agents》，看看它能不能把一篇方法文章整理成方便回看的中文笔记。

提示词如下：

```
请使用已安装的 Summarize 技能，总结 Anthropic 的公开文章《Building effective agents》。输出中文5个核心观点、工作流与智能体的对照表，以及给初学者的3条实践建议，保存为一份可打开的Markdown报告。
```

实际运行约4分钟，Summarize 命令先提取完整正文，再由当前会话整理成中文报告。这次没有额外配置摘要服务的密钥。

下面是完成后展开的执行记录，可以看到它确实调用了技能提取正文：

## 3、Academic Research Skills：从选题走到论文结构

长文章可以先读摘要，轮到自己写论文时，还需要知道去哪里找材料、各章该讨论什么。

你平常有没有遇到这样的问题：选题已经定了，面对空白文档，却不知道如何搭结构，也担心 AI 随手编出参考文献？

**Academic Research Skills** 按论文规划、文献研究和审阅等环节组织技能。小灰这次让它处理一个完整的小任务，提示词如下：

```
帮我规划一篇关于「AI Agent 在教育领域应用」的论文结构，并检索相关文献。请实际调用 Academic Research Skills，交付论文规划和分组文献阅读表，核对文献元数据，未核实的条目单列，不编实验数据。
```

初次安装遇到下载问题，补装后已能在技能列表找到论文规划和研究入口。执行时也实际加载了这两个子技能，下面是运行中的界面：

## 4、Bloom：一对一 AI 私教

你平常有没有遇到这样的问题：想系统学点新东西，网上教程一大堆，却不知道从哪里开始，也没人告诉你自己到底学会了没有？

**Bloom** 把学习拆成大纲、单篇课程、标注困惑、反馈和下一课几个环节。安装后可以直接告诉它想学什么，再围绕生成的课程继续交流。

小灰这次用的提示词如下：

```
我想零基础学 Python 数据分析，给我出一套一对一的自学课程
```

安装时遇到了下载和中文目录解压问题，WorkBuddy 处理后，已能在技能列表里搜到主技能 bloom-tutor。课程案例约 1 分 17 秒完成，生成了大纲和第一课两个文档。

下面这张图是生成后的对话和展开的执行记录，可以看到 4 个模块及对应学习目标：

## 二、思维与决策

## 5、魔鬼代言人：让别人先来挑毛病

学习时需要有人讲清楚，做计划时有时更需要有人反对一下。

你平常有没有遇到这样的问题：一份计划自己越看越满意，拿去讨论，却发现别人问的几个问题都没考虑过？

**魔鬼代言人（Devil’s Advocate）** 会找出方案里的隐含假设，再追问证据和失败条件。小灰这次选了一个日常活动策划案例：请它给周末旧书交换方案挑毛病。

提示词如下：

```
请实际读取并使用已安装的 devils-advocate 技能，审查下面这份周末旧书交换活动方案。方案：社区活动室周六14点到17点举办旧书交换；参与者每带一本书领一张换书券，每张券可换任意一本书；不提前报名，不限制书的类别和品相；计划安排2名志愿者负责收书、发券和维护秩序；活动结束后未换走的书统一捐赠。请找出5个最值得担心的问题，逐项指出方案中的依据、可能后果与最小修改办法，再给不超过6项的执行前检查清单。只分析这份方案，不编参与人数、成功概率或已经取得的授权，不联系任何人，不实际举办活动。短段落、每段约100字，不用宽表格，保存并打开中文Markdown报告。
```

这次约1分13秒完成，生成了《旧书交换活动方案审查》文档。下面是运行中的界面，可以看到它实际加载了指定技能：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/vsAViaKGWic0XoBTtmSeoicILP0fupwWiaQOutvk186FbZPulyTwktcjZibjUEyIe4nb9ZbjaOt4WKN8PgPt2ZXPbXHEzDmjkVnCB4WsYAVvu3uM/640?from=appmsg#imgIndex=11)

打开报告，它没有只说“注意公平”，而是追问：如果不检查品相，残破书也能换热门好书，后到的人会不会有券却无书可选？对应的修改是先验收再发券，并说明不保证能换到合意的书。

下面这张成品图，能看到它把方案依据、可能后果和最小修改办法写在了一起：

![](https://mmbiz.qpic.cn/mmbiz_png/vsAViaKGWic0UZAGYAwg5ElOUZGAdaTB8LzlbTiaV1gUFyHqFbAmeQoQC8Fxu24L9znLCWkYqc5FLoI7dWzllYTGY4SFGS51LsJYFelI99n6fo/640?from=appmsg#imgIndex=12)

另一个容易漏掉的问题是“剩余书统一捐赠”：交书者是否同意？接收方收不收？如果捐不出去，谁负责保管？它据此列出6项执行前检查事项，下面是报告末尾：

它适合在活动策划、产品提案等方案初稿完成后，先帮忙查漏。把具体规则写清楚，它才更容易提出有针对性的反对意见。

## 6、白毛股神 Serenity：整理投资研究问题

给方案挑完毛病，再看一个更需要分清事实和判断的场景：研究一家公司。

你平常有没有遇到这样的问题：新闻说某家公司受益，机构也持有，但具体靠什么赚钱、这些信息能说明多少，自己还没理清？

**Serenity** 提供一套投资思维框架，关注产业链瓶颈、机构行为和技术变化。小灰拿英伟达做了研究笔记案例，重点看它能否把问题拆清楚。

提示词如下：

```
用 serenity-perspective 技能研究英伟达（NVDA）的长期竞争力，重点拆解它在AI产业链中的位置，以及怎样判断机构资金的态度。区分芯片设计、制造、封装、服务器与云客户，说明利润来源和主要依赖；解释机构披露的报告期、滞后性与持股变化，给出核查表。引用资料写清日期，查不到的数字不填，不把机构持有等同看多，不给买卖建议。保存中文Markdown研究笔记。
```

本次约8分钟完成。执行详情确认读取了指定技能文件，随后核对公司公告和披露规则，交付一份独立笔记。

下面截取成品产业链表的前三列：各环节做什么、与英伟达有什么关系、利润从哪里来，放在一起看，比一上来判断“值得买”更容易理解。

## 7、cc-thinking-skills：提前推演计划会怎么失败

## 14、Wondelai：从产品想法走到访谈问题

查公司要找证据，梳理自己的产品想法，也得想清楚接下来找谁聊、问什么。

你平常有没有遇到这样的问题：脑子里先有了一个小程序或 App 的点子，却说不清用户为什么要用、现在又怎样解决问题？

**Wondelai** 把商业、产品和设计方法整理成技能。和之前的书籍蒸馏工具相比，它提供现成框架。这次实际装入65个，案例选的是 `jobs-to-be-done` 。

它会追问：用户在什么情况下想完成什么事，现有办法哪里不方便。小灰用下面的提示词测试：

```
用 Wondelai 的 jobs-to-be-done 技能分析「小区团购小程序」想法。没有用户访谈或交易数据，请把居民、团长、平台三类需求写成待验证假设，列触发场景、任务、替代办法、可能痛点和反证信号；再给不诱导用户的访谈问题与6个最小验证动作。不编评分或付费意愿，保存中文Markdown报告。
```

这次约2分49秒完成，实际读取的是新装仓库的技能及参考文件。下面是运行中制作报告的画面：

![](https://mmbiz.qpic.cn/mmbiz_png/vsAViaKGWic0Xaxoiau4OfsMNObeyia4gk8t2OfELvObAWNUu11330Xh6kgljObkNWbnbTvtk41MwlBzxLAmkby4uDt82VFZXHJaAehSYxNErXc/640?from=appmsg#imgIndex=36)

报告把三类角色分别展开。居民侧关注采购是否适合生活节奏，团长侧关注交接和投入，平台侧关注异常有没有人处理；这些都列为需要访谈检验的假设。

访谈问题没有问“你会不会用这个小程序”，而是让对方回忆最近一次购买、交接或异常处理。下面是打开文件后的提纲：

## 15、marketingskills：写好首封邮件和后续回复

需求想清楚之后，还要和潜在读者沟通。最后这个技能包，小灰用它来写一组专栏筹备邮件。

你平常有没有遇到这样的问题：想问问读者真正需要什么，却把第一封邮件写成一大段推销，后面也不知道该怎样继续聊？

**marketingskills** 提供邮件、文案和转化优化等营销技能。本次安装版本包含53个模块，实际调用的是 `cold-email` 。它强调短主题、同辈语气、每封一个容易回复的问题。

小灰把场景限定为已主动订阅读者，先了解需求。提示词如下：

```
请使用 marketingskills 中的 cold-email，为「程序员副业」知识付费专栏写一组中文筹备邮件，包含首封、两封跟进和没时间、没方向、担心投入后没结果三类应答，保存Markdown。读者已主动订阅，当前只确定主题，价格、上线时间和课纲尚未确定。围绕了解需求、邀请回复写完整文案，每封正文不超过150字，只设一个回复动作。不用占位符，不编个人经历、成功案例、收益和稀缺名额。待补资料单列，不连接邮箱、不发送。
```

约1分半生成了完整文稿。下面是完成后展开的真实执行记录，可以确认调用了邮件技能：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/vsAViaKGWic0WKJLicq3SCdqiblLrnl0QgazZOMxO3GUeCgCxdj9gfOljShteCLkWiaVt2jDTicRHBwShicD0TZjsFa8I6tD0xvIjjYzuvwHQX7yeA/640?from=appmsg#imgIndex=39)

## 五、做个总结

讲了这么多，可能有些小伙伴依旧会感到迷茫：“这15个技能，我该如何选择呢？”

这些技能各有各的适用范围，能够解决不一样的现实问题。为了加深大家的理解，小灰把它们归纳到下面的表格当中：

| 想解决的问题 | 可以先试 | 本次产出与使用提醒 |
| --- | --- | --- |
| 筛选B站视频 | Agent Reach | 检索清单与简介摘要；本次未取得登录字幕 |
| 快速读长文章 | Summarize | 中文要点、对照表和实践建议； |
| 从选题开始写论文 | Academic Research Skills | 6章规划、9篇分组文献与检索记录；继续精读全文 |
| 系统自学 | Bloom | 课程大纲和第一课；可继续反馈困惑 |
| 给具体方案找漏洞 | 魔鬼代言人 | 5项漏洞及修改动作、检查清单；先把方案写清楚 |
| 整理投资研究问题 | Serenity | 产业链表和机构披露核查表；研究笔记不替代投资判断 |
| 提前推演失败风险 | cc-thinking-skills | 定性风险和预防动作；点名对应框架 |
| 将演讲剪成短片 | YouTube Clipper | 两条双语字幕MP4、章节与文案；本次为横屏成片 |
| 制作可操作原型 | baoyu-design | 能添加文章、筛标签的阅读器；RSS为离线演示 |
| 制作网页动画 | GSAP | 可打开的标题与滚动动画；中文排版需微调 |
| 制作动态图解视频 | HyperFrames | 30秒中文配音字幕MP4；当前用主技能入口 |
| 排查续费问题 | dbskill | 候选原因、所需数据和验证步骤；补数据后继续分析 |
| 面试或合作前查公司 | Enterprise Company Research | 公开资料报告、来源分类和核查清单；重要原件另核实 |
| 梳理产品需求 | Wondelai | 需求假设、访谈问题和验证动作；接下来找用户交流 |
| 起草读者沟通邮件 | marketingskills | 首封、两封跟进和3类异议应答；按已确认产品信息续写 |

如果你主要写内容，可以先试 Summarize 和 YouTube Clipper，分别省下长文整理与字幕剪辑的时间；如果你想把点子做成看得见的东西，可以从宝玉设计或 HyperFrames 开始，打开文件就能检查效果。

建议大家先挑选一个眼下用得上的小任务，看看交付物和返工量，再决定要不要放进日常工作就好。
