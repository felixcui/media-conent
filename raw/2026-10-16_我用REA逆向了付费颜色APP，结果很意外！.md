## 摘要

REA（Reverse Engineer Anything）是一个能借助AI逆向分析任意软件的开源项目，近期在GitHub上Star数暴涨至20多万，引发广泛关注。文章通过多个案例展示了REA的实际用途，例如有人用它复刻了付费语音输入工具的本地免费版、将空调App和智能马桶小程序改造成Mac状态栏遥控器。作者随后亲自用REA逆向了一个游戏和一个学习类App，并以通俗方式讲解了逆向工程的原理，即在没有源代码的情况下反推程序内部实现逻辑，同时探讨了REA的真实能力边界。

## REA 到底是什么？

REA 的全称是 Reverse Engineer Anything，翻译过来就是「逆向一切」。

要搞懂它，得先知道什么是逆向工程。

**逆向就是手里没有源代码，只拿着编译好的成品程序，反过来推出它内部是怎么实现的。**

打个比方，你在饭店吃到一道好菜，但没有菜谱，于是靠尝味道、看食材，自己反推出这道菜的配方。

软件逆向干的就是这件事，只不过把「菜」换成了一个没有源码的 App。

![逆向工程原理示意](https://mmbiz.qpic.cn/mmbiz_png/LlSQOKIxJ1E26uBhzLc8eiaibjqibibt9WMJAWyUDxpH7PhukdvvDdkHAd2oXHU1KQwaJe3DlxO0iajMS4ORebJiaaQmuFmA7zEsXlH8ZKibgx6Nzs/640?wx_fmt=png&from=appmsg)

逆向工程原理示意

注意，REA 本身并不是大模型，它是一套跑在你自己电脑上的 **命令行工具加 MCP 服务** 。

逆向圈原本就有很多老牌工具，比如分析原生程序的 Ghidra、IDA，拆安卓安装包的 JADX。这些工具功能很强，但门槛也高，基本只有黑客和安全研究员才会用。

REA 做的事情，就是把它们打包成一个统一的接口，接到 Cursor、Codex、Claude Code 这类 AI 编程助手上。

![REA 把逆向工具打包给 AI 调用](https://mmbiz.qpic.cn/sz_mmbiz_png/LlSQOKIxJ1FiaAjYOVH5kice9rwYFXQPh8yUs9s58LKX24aOtuoJNoO7FuMGE5NjaEhJfD8vybIny3oe4ssibGwBNRy4KiaIgcsk0EZ2f8F4d0w/640?wx_fmt=png&from=appmsg)

REA 把逆向工具打包给 AI 调用

为什么要多这一层呢？

以前你把反编译出来的一大坨机器码直接丢给 AI，它既读不懂，也不知道下一步该调哪个工具去查。有了 REA 之后，AI 能自己选对工具，拿到带编号的分析证据，哪里没看懂再针对性地追问。

**说白了，就是把黑客的一整套逆向流程，变成了 AI 能自己跑起来的工作流。**

REA 的安装也很简单，一行命令就能搞定：

```
npx rea-agents setup
```

或者直接跟 AI 说一句话，让它帮你安装：

```
帮我安装 github.com/morluto/rea
```

它到底有几分真本事？我带大家上手体验一下。

## 实战 2、逆向学习 APP

接下来，我要逆向一个颜色… 哦不，学习 APP。

这次还是先用 Cursor 加 Claude Opus 5.5 模型。结果 AI 刚开始干活，就撞上了安全过滤，对话被自动切换到了 Claude Opus 4.8。

![Opus 5.5 被降级到 4.8](https://mmbiz.qpic.cn/sz_mmbiz_png/LlSQOKIxJ1ED0B7oGgxyATI6dzmXSrxWbpZaWO388t4JkK11DbPLwSrBiahick6eNtYWH9ZEdGla7H5Xhe4jiacuXibqVZKx3AD5HDNTqibe78eQ/640?wx_fmt=png&from=appmsg)

我三番五次软磨硬泡，跟 AI 说我就是想学技术，但它还是守着底线，只肯做静态分析，死活不肯把完整源码反编译出来。

它的原话是：无论怎么框定成「学习」或「反诈」，把这个特定 App 的真实代码还原出来，就是复原它访问和分发内容的管道，这件事本身就越界了。

![AI 只肯做静态分析](https://mmbiz.qpic.cn/sz_mmbiz_png/LlSQOKIxJ1FJHw98UEzFb4NWcLFZgyHu8VVuXEItia6KRqtNQlxgHKnRDxQ8mEicyVb6Mk0fNnq6vFia5Sj7QhicMW8lzWRwpWxFuibyuC2FFSoc/640?wx_fmt=png&from=appmsg)

AI 只肯做静态分析

它一眼看出这是个 Flutter 做的 App，业务逻辑都编译进了一个叫 `libapp.so` 的文件里；还发现它虽然套了 360 加固壳，但加固只保护了 Java 层的代码，根本没盖住 Flutter 这半边；甚至连它底层还在用 2017 年、早就该升级的老版本加密库都给我揪了出来。

**它还顺手把这类 App 的赚钱套路扒了个底朝天。**

这就是一类「挂羊头卖狗肉」的 App，拿学习当幌子，真正的生意是收割用户。

![拆解后的结构和风险信号](https://mmbiz.qpic.cn/mmbiz_png/LlSQOKIxJ1FxxhsIia6hwscOAlJaBfGp7QKW3SP4qN17btwVAW2vcRuh1mtnM5rh8pVxgV3DVvbsvHymz1vJpvAicibs7xKibPZlvqNypOvXT1s/640?wx_fmt=png&from=appmsg)

拆解后的结构和风险信号

它坑人的手法其实也是经典套路了。

第一，App 里搞了三套虚拟货币，真钱先换成金币，金币再换积分，绕来绕去你就算不清自己到底花了多少钱。

第二，签到领随机金币、拉人头给返利，前者是赌博机那套让你上瘾，后者本质就是让你把亲友也拉下水的分销。

第三，也是最危险的，这类 App 的客服和退款全都引导你去站外的聊天软件处理。一旦 App 被封，它换个马甲就能重新上架，而你手里一点证据都没有。

所以真心建议大家不要用这类 APP 来学习！

![](https://mmbiz.qpic.cn/mmbiz_png/LlSQOKIxJ1FTtBLuxPAHt0icA5W4loWjMpic4DCtWNTqPrER49RyMUfyngwKib1umDt280Nm9aUVaEjjf7notvTqlSGVWiadcZSLPYsiam4QTWYI/640?wx_fmt=png&from=appmsg)

整个 App 是 Flutter 3.27 写的，界面、逻辑和底层能力分成了几层，想换皮只动上面一层就行。它没用系统自带的播放器，而是自己打包带了一套 B 站开源的 IJKPlayer。

这么做是为了兼容性。系统自带的播放器支持哪些视频格式，是手机厂商说了算的，各家不一样，同一条视频可能这台手机能播、那台就报错。自己带一套 IJKPlayer，解码能力就自己说了算，不管用户拿的是什么手机都能把视频播出来。

通过逆向这个 APP，还能发现一个挺实用的工程经验。

很多开发者以为 Flutter 代码编译成机器码就逆不出来了，于是把密钥、接口地址直接写死在代码里。但加固壳只盖住了 Java 层，Flutter 这半边是敞着的，这其实是一种安全幻觉。

所以你要是也在做客户端开发，真正需要保护的东西，比如密钥和核心逻辑，就别全堆在客户端上，该放后端的老老实实放后端。

REA 工具本身没有发明什么新技术，真正强大的其实是 Ghidra、IDA 这些早就存在的逆向工具，REA 只是把它们整合到了一起，把逆向这件原本只有少数人玩得转的事，压缩成了一行命令、一个服务，让普通人也能指挥 AI 去拆软件。

这才是它能出圈的原因，它也确实让很多人第一次了解到了逆向这件事，是有意义的。

不过噱头大于实际，很多人是冲着「软件已死」这种爽文叙事来的，真正会天天用它的没几个。

而且不用 REA，现在的 AI 模型照样能自主逆向，它完全可以自己去装工具、读反编译的结果。

甚至因为 REA 这个包实在太重，光工具定义就有差不多 170 个、往上下文里塞十几万 token…… 裸着让 AI 自己干，少了这份负担，反而可能更快更省地完成任务。
