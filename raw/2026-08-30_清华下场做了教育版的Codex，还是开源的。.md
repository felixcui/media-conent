# 清华下场做了教育版的Codex，还是开源的。

**作者**: 阿颖

**来源**: https://mp.weixin.qq.com/s/f8dKGPJDkNetDqunsOKxRw

---

## 摘要

清华大学开源的OpenMAIC类似教育版Codex，能根据学习目标自动拆解任务、规划并生成课程，支持随时提问互动，还可复刻教师风格。作者体验后认为，传统机械式传授知识的课程价值已降低，更愿为个人经验与判断付费。

和一个还在做 AI 教育培训的老板闲扯，我说兄弟，ChatGPT、豆包这些 AI 产品都已经这么强了，随便问什么问题，它都能通俗易懂地给出，你那卖课的生意怎么还能有市场？

反正我很久都没打开得到 App 了。

**这哥们告诉我说，市场在收缩，但仍然还是有市场。**

因为很多用户早已经习惯了通过课程学习。就像 B 站，教程仍然非常受欢迎。

ChatGPT 能回答问题，但大部分人要的不只是答案，而是一整套视频课程，这样有人能带着他逐步往前走。

而在这样的学习场景里，ChatGPT 更像助教，跟课程是互补关系。这么说也有道理。

**不过，我随即又想起之前自己用过的一款清华大学做的 AI 驱动的课程产品 OpenMAIC，应该挺多人不知道。** 我把链接发给了他。

结果这货晚上回去给我发消息说，他突然觉得很多课已经没有存在的意义。

![文章图片](https://mmbiz.qpic.cn/sz_mmbiz_png/iagroyM7YaBnQJmOqGasgFmnxAgIXLicTrFobMic4qUQ5K7oT4ZKX1chaFIPuGX9BveyPHuu0nfGVia4kXTn6uJTwGCHceS4ZTZwwyeHB93icuHQ/640?wx_fmt=png&from=appmsg)

并且，OpenMAIC 是基于 MIT 协议开源的，任何人都可以部署。

最近，这个产品又有不少更新，我感觉它现在已经越来越像教育领域的 Codex 了。强烈推荐大家试试。

它可以根据你的偏好和已有的背景知识，直接生成一门课。而且在学习的过程中，哪里搞不懂，随时打断提问。 **这才是真正意义上的因材施教。**

**至少对我来说，这种学习方式肯定比坐在那里机械地听另一个人把一套固定内容从头讲到尾要好很多。**

所以我越来越觉得，AI 时代，市面上很多课的价值感已经很低了。

以后如果还要花钱买课，我更愿意为一个人的认知和判断付费。

**比如他在某个领域真的做了很多年，有一些 AI 很难直接给你的经验、判断，甚至是他自己踩过的坑，这些东西当然有价值。**

但如果一个老师提供的主要就是知识本身，把网上已经有的东西重新整理一遍，再从头到尾讲给你听，我觉得这种课的意义已经不大了。

不废话。我给大家演示下 OpenMAIC 的 Pro 工作台。 **它的界面真的和 Codex 等等产品非常接近，只不过 Focus 在教育场景。**

[前半年我用 OpenMAIC 的时候](https://mp.weixin.qq.com/s?__biz=Mzg5Mjc3MjIyMA==&mid=2247581054&idx=1&sn=851e52c69d6e08f6f43ed59806d291fe&scene=21#wechat_redirect) ，它生成课程的逻辑还比较像传统的 workflow。给它一个主题，它会按照预先设计好的流程一步一步往下拆，最后生成一门课。

但这次再用，感觉已经明显不一样了。

**OpenMAIC 越来越像 Coding Agent，我只需要给它一个具体的学习目标，然后 Agent 会根据这个目标自己拆解任务，规划课程，选择合适的教学方法，再调用不同的工具，最后把整门课设计出来。**

也是体验完这个产品之后，我突然意识到垂类 Agent 最后的结构，会越来越像今天的 Coding Agent，都是模型 + 工具 + Harness + Memory。

我给大家完整跑一遍流程。

比如这两天，我正好想系统学一下 Agent Harness。

**现在我只要把学习目标告诉 OpenMAIC，比如为零基础学习者设计一套七天 Harness 课程，它就会先了解我的背景、目标和学习偏好，再自己拆解任务、规划课程，并开始生成课程。**

下面这段就是完整过程。

生成的时候，大家可以看到我调用了一个 Skill。其实 OpenMAIC 目前内置了很多专业的课程设计 Skill，大家可以直接用，我做了张表，汇总了目前部分可用 Skill。

生成完课程后，我觉得还是希望能够增加一些练习题。 **所以，继续迭代。** 其实这个过程就和我们在 Codex 里 Vibe Coding 一模一样。

如果大家在本地部署这个项目，还会发现它有一个特别有趣的 Skill。

**它可以直接解析一段教学视频，分析这个老师的讲课风格，然后再提取讲解者的音色，最后把整套表达方式复刻出来，迁移到新的知识内容上。**

也就是说，你可以先给它一段你喜欢的教学视频，让它学这个人的讲课方式和声音，再用同样的风格去讲一个完全不同的主题。

这个能力目前只在本地部署版本里有，大家有条件的话可以试一下。音色复刻这里用的是面壁的 VoxCPM 模型，我自己感觉复刻效果也相当不错。

**而且 OpenMAIC 甚至还做了一个教育版的 Arena，这个功能挺有意思。**

同一个教学任务，它会同时交给两个匿名模型，分别生成一套互动课件。我们可以先实际体验，再给自己觉得更好的那一个投票，投票结果最后会进入排行榜。

**这样其实他们就能很直观地判断，到底哪个模型更擅长把一个知识点做成真正能用的互动课件。** 这个思路真的好巧妙，感觉很多产品都可以借鉴。

话说，本地部署这个项目也非常非常简单。直接像我这样，把链接发给 Codex 等 Agent 就行。

[我也把这个项目推荐给了我们团队的实习生。](https://mp.weixin.qq.com/s?__biz=MzY4NjM2NTU1NQ==&mid=2247483951&idx=1&sn=6cf91a05eb0e76497413416e535f6845&scene=21#wechat_redirect) **我觉得，这类产品往大了说，本质上就是一种教育平权。**

因为你想学什么，就直接告诉它。它可以拆解学习路径，设计课程，选择教学方式，中间哪里不懂随时停下来问，觉得讲得不好还可以让它换一种方式重新讲。

过去一门真正好的课，其实很贵。真正既懂一个领域，又知道怎么把它讲明白的人，本来就很少。

所以市面上很多课程真的都是粗制滥造，他们找一些公开资料，重新整理一下，再录成几十节视频。

但 AI 出来以后，这件事的成本正在快速下降。一个普通人可以快速生成一套根据自己基础设计的课程，以及一个随时可以打断的老师……

**这就是新时代的慕课啊。**
