# 突然发现，Video as Code 的时代已经来了。

## 摘要

文章指出“Video as Code”时代已至，Claude Motion与国内Fotor Agent均可通过自然语言和代码时间轴生成MG动画，实现文字、数据与动画的精准可控和便捷修改；Fotor Agent主攻零门槛、原生4K的代码生成视频，适合科普、产品介绍和商业汇报，并对比传统视频生成模型，强调代码路线在信息解释与准确性上的优势。

最近发现，X 上越来越多人开始用 Claude Opus 模型制作视频了。对，你没看错，就是那个 LLM 模型。

![文章图片](https://mmbiz.qpic.cn/mmbiz_png/iagroyM7YaBkVJDeuQz4qhE4jmYS4AViaWhg0RHtt1OgEQDB5XRW0aO8Y57rZicFeaab9wTWyla0HdDpdDGl9jYbJibGbIibfbp9r6ySceibzTf9g/640?wx_fmt=png&from=appmsg)

**尤其是一些 MG 动画，动态字体、图形转场，还有各种复杂的视觉效果，做得相当漂亮。**

甚至 Anthropic 官方在 10 月 8 日推出了一个叫 Claude Motion 的新功能。

Claude Motion 可以直接通过自然语言制作 MG 动画。

**比如把一份季度报告交给 Claude，让它提炼重点，再通过动态图表、文字和各种转场效果，制作成一段 30 秒的讲解视频。**

它的实现思路非常有意思。

你可以把它理解成，给网页增加了一条时间轴。平时我们开发网页，通过代码决定文字、图片、图表等元素的位置和样式。

**现在，再增加一个时间维度，让代码控制这些元素什么时候出现、怎么运动，画面就动起来了。**

举个例子，一个柱状图可以在第 1 秒从底部出现，第 2 秒增长到指定高度，第 3 秒显示具体数字，第 4 秒切换到下一个场景。

而且，因为底层是代码，里面的文字、数字、动画时间都可以继续修改。但在国内想用 Opus 的模型，得费老门子劲。

这两天有个让我非常惊喜的发现，国内也出了一款死磕代码生成视频路线的产品，而且做得非常之扎实。产品名字叫 Fotor Agent。

它早在 8 月份就在海外上线跑通了这条路线，还顺手拿下了 Product Hunt 第一，那时候 Opus 还在刷屏。现在，国内版本也终于正式上线了。

Fotor Agent 主打用代码生成视频制作 MG 动画，只需要用自然语言说清楚需求，就能制作原生 4K 的 MG 动画以及带 MG 动画的视频。

**不仅文本精准可控，还真正做到了零门槛，完全无需 AE 基础。**

无论是商用还是自媒体创作，都能完美适配。

MG 可能有些同学不熟悉。其实它是 Motion Graphics 的缩写，通常翻译成动态图形。说白了，就是让文字、数字、图表、几何图形等视觉元素动起来，用动画来表达信息。

**所以，MG 动画特别适合做科普视频、产品介绍和商业汇报。** 因为很多抽象的概念，光靠语言或者静态图片，很难解释清楚。但通过图形和文字的动态变化，就容易理解多了。

不过，当动画开始承担解释信息的任务，准确性和可控性就变得非常重要。尤其是涉及数据的时候，光有漂亮的画面还远远不够。

假设我想制作一条 AI 模型的科普视频，里面有一个展示模型性能的动态柱状图。

我肯定需要保证数字正确、文字正确、每根柱子的长度正确，还需要根据解说安排动画出现的时间。

**对于商业和自媒体视频来说，这些事情比单纯追求画面的视觉冲击力更加重要。**

这种场景中，代码生成视频这条技术路线就非常有优势，因为它可以直接通过代码控制每一个元素。比如柱状图的高度、文字内容、动画出现的时间，都可以精确调整。

**我给大家看看 Fotor Agent 做的一些 MG 视频。** 原生 4K，而且可以直接用在商用和自媒体场景。

比如，这是一个 JOJO 风格的动漫视频。

这是一个数字人访谈的视频。

总体来说，现在利用 AI 制作视频，大致可以分成两条技术路线。

第一条，就是我们非常熟悉的 Seedance、可灵、MiniMax H3、Vidu 这些视频生成模型。

它们擅长根据文字、图片等输入，生成连续、复杂的动态画面。 **比如逼真的人物、自然风景，或者有电影感的镜头，这些都是视频生成模型擅长的事情。**

不过，视频创作还有一类很常见的需求，就是通过动画，把复杂的信息解释清楚。

比如，我想制作一条科普视频，介绍过去十年 AI 模型参数量的变化。这里需要准确的数据、动态柱状图、文字说明，以及配合解说节奏的转场。

这种内容，其实就非常适合用 MG 动画来呈现。

**而让我觉得有意思的是，随着 Coding 模型越来越强，现在已经可以直接让 AI 编写代码，制作出这类动画，完全不需要调用传统的视频生成模型。**

这就是另外一条技术路线。

如果硬要用 Seedance 这样的模型制作 MG 动画，当然也可以尝试，但往往会碰到两个问题。

第一，文字和数据的准确性不太容易保证。

**第二，后期修改非常麻烦。**

毕竟视频模型生成的是连续画面，假如你只是想修改一个数字、一句文案，可能又得重新生成对应的片段。

**空说没有意思，我给大家看一下我用 Fotor Agent 做的国风历史科普短片的一个 MG 动画。**

下面给大家演示一下。这是 MG 动画快速上手的入口。

在右边输入视频解说主题，选择风格。接着上传图片素材，选好画面比例，就可以开始生成了。这里最多支持上传 30 个文件，图片、视频和文档都能添加。

**发送完视频生成任务后，跟着提示，把脚本要修改的地方改了，旁白的声音选择了，分镜方案确定了后，就 OK 了。** 过了一会就生成出来了。

值得一提的是，一个 1 分钟的 4K 超高清 MG 视频跑出来的花费不到 30 元，成本确实不高。

界面左侧的时间轴，文字、画面、配音和配乐都已经自动排进各自的轨道里了，它把所有素材打包成了完整的视频工程，后面可以继续接着编辑。

这一步省掉了不少时间。以前做这种片子，脚本、素材、动画和配音得分开准备，最后还要导进剪辑软件，一段段对齐时间轴。

现在这些工作都能在 Fotor Agent 里完成。尤其是个人创作者，不用来回切换好几个工具，就能把脑子里的想法一直推进到成片。

**Fotor Agent 生成的视频是原生 4K 的 MG 动画，我们可以直接导出 4K。** 整个片子中文字完全没有出现乱码现象。

像这种科普片，文字和图形的清晰度和表达的准确性就非常重要。AI 视频模型常常在这里翻车。

像片子里的竹简展开，印刷时刷墨、覆纸、揭纸等，这些都做成了动画，观众能跟着画面看懂每一步。

用 AE 做，通常要进行拆素材、搭图层，再设置关键帧等等操作，逐个调整先后和快慢。会用 AE 的人当然能做得很细，但对没有基础的人来说，光熟悉这些操作，就得花不少时间。

**现在直接零基础上手，把素材直接给到 Fotor Agent，用自然语言描述，先生成一版，再根据效果调整。** 不用先学会 AE，也能开始做这种 MG 动画。

一个人做视频，前期学习和制作的负担都小了不少。

而且，生成之后，画面里的各种元素还能继续改。

**视频中文字、数据、图形和背景等 MG 元素，Fotor Agent 都能精准地在视频中直接编辑。** 需要改哪一处，就直接改哪，不用重新生成，大幅节省了成本。

比如，这里我可以在中间的画布区域里直接改文字。

![](https://mmbiz.qpic.cn/mmbiz_png/iagroyM7YaBnLYvK8ZdGIV8Bia2vElDVCr22VuEznTXIibowy91MtJBHVdIrUfIvxqWLHxv1JzXTadxt43KHib4DPdGtZQgSzicXgoCNKZEUFWlU/640?wx_fmt=png&from=appmsg)

还可以对图形进行圆角、透明度、描边等等调整。

改动比较大的话，可以去右侧的对话框中输入要求，就能进行对应的修改。

**更省心的是，在 Fotor Agent 里，生成后的视频、音频、字幕和 MG 动画都有各自独立的轨道。** 想调整哪个元素，直接去对应轨道上拖拽或替换就行，方便又精准。

我随手又做了一个品牌主题片，效果还不错。

除了做动画，它也能帮忙剪视频。 **上传口播，可以清理语气词和废话，再配上画面。** 长视频也能挑出重点，剪成短片。剪完想再调，直接在时间轴上改就行。

我放了张图，大家可以看看，这就是 Fotor Agent 在做的事情。

它和前面介绍的用 Claude Opus 制作 MG 动画，底层思路是类似的，都是通过代码生成动画。

只不过，Fotor Agent 把这套能力做成了一套更完整、门槛更低的 Agent 工作流。

**我们只需要上传必要的素材，告诉它自己想做什么，它就会规划内容、生成动画，再把各种素材组合起来，制作出一个可以继续编辑的视频初稿。**

而且，修改也非常简单，就和改 PPT 一样。

我自己还是挺看好 Video as Code 这条技术路线的。

这段时间，我们正在密集制作一些产品宣传视频。我发现，其实很多时候，我们并不需要特别复杂的创意，更多的就是把信息清楚地传递给用户。

而这类视频里面，有大量元素是可以反复复用的。

比如 Logo、品牌动画、特定的图标、一些固定的转场效果，都可以通过代码做成组件，后面需要的时候直接调用。

包括我们平时制作口播视频，也经常需要添加花字。

每个博主通常都有自己的视觉规范，字体、颜色、动画效果基本都是固定的，只有具体的文案会发生变化。

这些东西，其实都可以通过代码固化下来。以后制作剪辑类似的视频，只需要替换文字、数据或者其他参数，就可以沿用原来的动画效果。

这才是 Video as Code 最有想象空间的地方。
