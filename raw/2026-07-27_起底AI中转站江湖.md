## 摘要

AI中转站是一门暴利且不透明的灰色生意，近期引得资本入局。该生意技术门槛极低，多基于开源项目快速搭建，背后实则分为正规代理、企业网关、地区差价商和灰色套利四种完全不同的模式。国内低价中转站往往依赖违规手段压低成本，其赚钱逻辑极度不透明，通过自定义站内虚拟货币汇率和扣费倍率制造低价假象，实则暗藏丰厚利润。

2026 年春天，AI 中转站这门略显灰色的生意，突然迎来了一位最不缺流量的玩家。

4 月，孙宇晨开始为 B.AI 站台，把「一个 Key 调用所有大模型」的生意，称作「AI Agent 的底层金融基础设施」。

这位币圈最擅长讲故事的中国商人，人称「孙割」（割韭菜的割），突然爱上了 AI 中转站生意。

他看中的是 **暴利，足够暴利。**

**但事实上，孙宇晨也不过是个姗姗来迟的后来者。早在资本和圈内大佬入场之前，一条围绕买号套利、拆分与分销的灰产链条，就已经野蛮生长多时。**

**也因此造就了一个极其庞大，甚至无孔不入的「 AI 中转站江湖」。**

🚥

接下来，分享我们对「中转站江湖」的梳理和分析。

中转站是一个「技术门槛非常低」的生意

首先，中转站在技术上几乎没什么门槛，因此引来了海量「创业者」分布在整个产业的上下游。

正常情况下，请求直接发给 Anthropic 或者 OpenAI 的服务器。 **用了中转站，你只是把请求地址换成它的域名，它验证你的账号余额，转发给对接的上游，再把结果原样返回。**

这套架构不用自己写。One API、New API 这类开源项目部署上去改几个配置，一天就能搭完一个能对接多家模型、能分销 Key、能算账单的中转站。

  
  

所以网上的中转站看起来几乎完全相同：统一接口、多模型、人民币充值、几折起售。

  
  

但它们背后其实是 **四种完全不同的生意** ：

【1】正规代理商：官方进货，再卖给你。过程合法合规；

【2】企业 AI 网关：企业自己付费购买模型，中转站只负责企业内部token调配

【3】地区差价商：海外代买，再转卖给国内用户

【4】灰色中转站：用违规手段（订阅号池、虚假账户、模型偷换）把成本压得极低

同样一个 /v1/chat/completions 接口，同样能接入 Claude Code，成本结构和能活多久完全是两回事。

提到中转站，不得不提聚合领域的标杆 OpenRouter。 **虽然 OpenRouter 并不属于本文接下来要重点讨论的那种靠「灰色套利、账号池与隐密分销」运作的典型中转站** ，但它作为全网最大的正规聚合平台，可以帮我们立下一个参照系。

OpenRouter 把每个提供商、每个模型的价格和数据政策全部公开，只在充值环节收一笔平台费。

**但很多人不用它，因为它虽是正品 Claude API，价格实在太高，** 基本等同于官方原价再叠加约 5.5% 的手续费，所以圈里戏称，在 OpenRouter 调 Claude 比直接调官方还贵。

  
  

而国内低价中转站宣传的价格，几乎是 Claude 官方的十分之一。

中转站到底如何赚钱？

国内中转站最常见的广告是「1 元充 1 刀」「全场 2 折起」。它能成立，靠的是好几个环节都藏着不写进价目表的利润。

余额里的「刀」不是美元，只是中转站自己的一套积分，充值汇率和模型倍率都由站长自己定。

  
  

所以同样显示 100 刀，在不同站点能买到的 Token 差好几倍：有的充 1 元给 5 刀、按 1 倍扣，有的充 1 元给 1 刀、按 0.2 倍扣，最后实际成本可能完全相同。

**我们让 Codex 梳理计算了一番，它「告诉」我们的付费逻辑大致是这样（R 为每 1 元人民币获得的刀数，M 为模型、用户组和线路的综合扣费倍率，L 为按官方价目表算出的美元标价）：**

```
获得额度：B = 实付人民币 A × R
扣除刀数：C = 官方标价等值 L × 综合倍率 M
实际人民币成本：Y = C ÷R= L × M ÷ R
每 1 美元官方标价等值的人民币成本：E = M ÷ R
```

是不是足够复杂？光看充值比例，根本看不出谁便宜谁贵。而算不清楚，恰好就给中转站留出了加价的空间。这套逻辑同样出现在孙宇晨的 B.AI 上。

  
  

利润究竟从哪来？

现在大量中转站的主要服务其实不是聚合，大多只提供 Claude 和 GPT 5.6 系列，像 DeepSeek 这类国产模型甚至作为福利免费发放。

而想赚到利润，模型来源就不可能是正常渠道，更不可能是 Claude 官方 API。

利润途径大致有这么几条：

**【1】批发折扣。**

靠企业合同或者大额采购拿到低于零售价的价格，再按接近官方价卖出，赚中间的差价。最干净，毛利也最薄，想长期把旗舰模型压到极低价，靠它行不通。

**【2】订阅拆分（这是主要路径）** 运营者买入大量 Claude、ChatGPT 的订阅账号，比如 Claude Max 5X。采购量很大，来源多半灰色，从淘宝的账号售卖情况就能一窥全况。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/a16Y4PLxPqmIbf5NrlTFia8oQ7JE4GDDLVUL5h1Ntf4QbICCnuz6OoolzQ8Q26ibnibVLPibzBqic1FKtiaF3QFRPXeZbbW6o8u8dq2WTnNz6Da4k/640?wx_fmt=png&from=appmsg)

Claude 严禁账号买卖和共享，也严禁不支持地区的用户购买，被封概率非常大。但售卖方却能提供质保，用了 7 天被封，扣掉手续费和这 7 天的使用费，剩下的全退。

**这种质保本身就说明账号来源非常灰色。**

之后，站长把这些账号组成账号池，把订阅实际能产生的用量按官方 API 单价折算成一个大得多的名义额度零售出去。

对应的模型倍率随封号概率调整，封得最严的时候价格急剧飙升。

  
![图片](https://mmbiz.qpic.cn/mmbiz_png/a16Y4PLxPqkic6Je198Vfic6qYYhPtNowELuJLYJGm8nBd6XP3cFS6DnfrLUliaZUOVB1HcrxmAxcA33THsDgbTXYv6FOIgpbK6heMWcIMXYDM/640?wx_fmt=png&from=appmsg)  

所以这算不上稳定毛利，更像一场统计学计算。

账号池要多少账号、以多大概率被封才能撑住用户量，账号寿命、并发上限、会不会用满额度，都要事先算清；上游一改规则或者大规模封禁，利润就归零。

**【3】往下分销。**

大站给代理更低的进货价，代理负责拉新、社群和客服，一层层加价卖给终端用户，站点从零售商变成了批发商。

**【4】偷偷替换模型。**

早期中转站还靠集齐几十个品牌做宣传，现在都只瞄准 Claude 和 GPT 系列。与此同时，国产模型的能力提升得比较快，之前比较火的 GLM 5.1 就大量被用来替换 Claude 的 API，它非常便宜，国内对这类反代订阅的管理也并不严格。

两者差价极大，把便宜的模型包装成昂贵的卖，利润直接来自用户分辨不出真假。

不过，现在 Claude Pro 成品号的二手售卖价格极低，基本已经逼近了「原价官方 Claude」账号。所以，中转站为了保持用户量，很多站长已经没有了「用假模型」偷偷替代 Claude 正版模型的动力。

所以，一个中转站到底能赚多少钱？

先看最正规的 OpenRouter。它覆盖 70 多家提供商、400 多个模型、1000 万用户，每月处理 200 万亿 Token，不靠低价模型或账号套利，规模也不小。

截至 2026 年 3 月年化收入已超 5000 万美元，5 月完成 1.13 亿美元 B 轮融资、估值约 13 亿美元，7 月 23 日《华尔街日报》报道 Stripe 正与它洽谈收购，潜在交易价最高可能达约 100 亿美元。

即便完全合规，只做 API 聚合这一层，也足以支撑一家独角兽。

  
  

再看国内。

  
  

这些中转站究竟能赚多少钱？目前公开报道中的数字，已经覆盖了从草根小站到千万级平台的不同规模。

最小的一类，可能只是个人搭建的小站。《中国新闻周刊》援引此前的媒体报道提到，一名原本在工厂车间工作的经营者，几乎不懂编程，只是照着教程，让 AI 帮自己搭建网站，再套上 New API 这一开源框架，最终也接到了真实用户。

这个站点平均每天能收到上千元到上万元的充值，简单折算下来，月充值流水大约在 3 万至 30 万元之间。

规模再往上，公开报道中已经出现了月流水数百万元的项目。2026 年 5 月，二十一经济网转载界面新闻的调查称，一位投资人关注的某个中转站项目，月流水约为 500 万元，毛利率接近 50%。

《豹变》2026 年 6 月的一篇报道中，一名刚入行不久的中转站站长称，业内「一些做到每月千万级别流水的公司」，团队甚至不到 20 人。

这句话透露出的行业图景很夸张，一个不足 20 人的团队，如果月充值流水达到 1000 万元，平均每名员工对应的月流水就超过 50 万元。按照一年计算，平台的年充值流水可能超过 1 亿元。

高流水背后的关键，是中转站能够把上游模型的实际调用成本压得远低于官方API价格。《豹变》举过一种典型的成本模型： **假设官方 API 每万 Token 售价为 1 元，中转站通过批量购买 Coding Plan、合并套餐额度和账号池等方式，可以把成本摊薄到约 0.2 元，再以 0.5 元出售。按照这一模型计算，每卖出 0.5 元的 Token，成本约为 0.2 元，毛利为 0.3 元，对应毛利率约 60%。**

低成本最终反映在对外售价上。《豹变》援引《21世纪经济报道》的调查称，当时 Claude Opus 4.6官方API输出价格约为每百万 Token 170 元，一家国内中转站已经将标价降至官方价格的五折左右，部分中小站甚至只有官方价格的二至三折。

但中转站并非稳赚不赔。建站几千元就能上线，真正的成本在账号池、代理 IP、支付通道、封号损失、退款赔付和补充上游资源，于是两极分化：头部凭规模和渠道拿高利润，中小站点长期在盈亏边缘甚至亏损。

2026 年 5 月 12 日，社交平台账号 **@YesterdayBigcat** 转发了一张署名「西瓜的皮」的声明截图：发布者自称是上海一家中转站经营者，因非法获取、转卖 API 资源（部分低价 API 通过「非法技术手段」获取）被刑事拘留 37 天，取保候审后完成退赔退赃并将面临罚金。

他还表示中转站最终并没赚到钱，甚至无力退还用户账户里的剩余余额。

  
  

高利润案例确实存在，但真正赚到钱的，往往只是链条最顶端的少数玩家。

数据转售

除了账号和模型层面的猫腻，更容易被忽略的是数据。

所有经由 Coding Agent 发出的请求都要过中转站的服务器，完整的代码仓库上下文、Prompt、报错日志，甚至调试时带出来的密钥，理论上都能被它看到。

会不会被留存、被拿去做别的用途，用户既无从知道，也无从验证。

2026 年 5 月，Oxford China Policy Lab 研究者 Zilan Qian 调查中国 Claude 灰色中转市场时采访了多名开发者，他们的说法是：API 加价只是获客，收集调用日志才是真正的利润来源。

  
  

这些日志包含用户输入、模型输出、报错信息和人工修改后的结果，可用于模型蒸馏、代码模型训练、产品分析或者转售。

据 Bright Data，公开市场上的普通网页或结构化记录低至每 10 万条几十到数百美元。

当然，普通抓取数据和高质量推理轨迹不是同一种商品，Claude Opus4.8 和 Fable5 模型下的高质量数据，也不是同一种价格。

凡是能用到 AI 的地方，中转站都无孔不入

中转站的应用场景，已经广到很多人根本没意识到自己在用它。

公开部分最经典：买 API，拿一个 Key 接入 Codex、Claude Code。

  

（CC Switch 中自由接入 Claude 中转站 API，在 Claude Code 中使用）

**但是，往深处看，中转站的商用场景就有点五花八门了，并且已经超出大部分人的「信任感」，比如悄悄嵌进各种 AI 编程产品的后台里，替换掉原有的 AI 请求，偷偷转换成自家的 API 中转站。**

这种场景出现的主要原因还是因为绝大多数用户根本没办法验证自己拿到的是哪个模型。中转站接入时只要提前写好一段系统提示词，用户再怎么套话、诱导它承认身份，也基本问不出真话。

只要一个产品用到 AI 能力，理论上都可能被这样偷换。

这里面有个非常经典的案例。

网上有人卖一种「Cursor 无限用 Claude 会员」的方案，价格便宜到离谱，每天能调用上千次。方案附一份教程，教你在 Cursor 里装一个外挂插件，插件里显示一个账号，每次调用按套餐扣次，甚至支持一键换号。

  

（此图为 Cursor 界面，左侧为该「插件」）

教程会特意强调，要在 Cursor 右侧的菜单里手动切换成原生支持的 Claude 模型。用户看到自己已经手动切到 Cursor 自带的模型，会下意识觉得这总该是真的了吧。

毕竟，插件里的调用次数也确实在真实减少，看起来像那么回事。

  
  

直到用 Codex 去查后台代码，才发现它根本没改动 Cursor 原生的模型逻辑，而是偷偷把调用模型的来源地址改成了一个网站，打开就是一个 API 中转站。

账号、次数、一键换号，甚至「手动切换模型」这个引导本身，全都是幌子。

  
  

真实调用的到底是不是 Claude 完全说不清楚，毕竟几十块钱买上千次调用，价格本身已经很说明问题。

**所以中转站进入产品的方式从来不止一个入口，它分散在每一个用到 AI 能力的角落，用户往往连自己被接管了都不知道。**

这一点也有第三方实锤。CISPA 的研究团队抽查了 17 个被上百篇学术论文引用过的中转接口，有的性能偏差能到 47%，接近一半没能通过模型指纹测试。

其中一个被标成 Gemini 2.5 的接口，在医学基准测试里只拿到 37 分，官方接口能拿到 83 分以上。

  
  

光靠价格高低，判断不出一个中转站提供的模型是不是真的。

而这样的评分本身也已经成了市场的一部分： **现在有很多 API 中转站评测网站，负责给每个站点的模型打「匹配度」分，而这种打分往往只需要 10~20 秒，所以打分本身是否真实，用户又完全不知道了。**

为什么会有如此错综复杂的中转站江湖？

根源在于官方渠道在国内买不到 ——OpenAI 和 Anthropic 的支持地区名单里没有国内，正规注册要海外手机号，付款要海外信用卡，KYC 也一年比一年严格。

尤其是 Anthropic， **最近又被曝出用诱饵邮件识别地区，甚至在 Claude Code 里做各种手脚，判断使用者是否来自中国。**

  
  

所以普通开发者面对这些前沿 AI，最先要解决的是能不能用，中转站先解决能用才轮得到便宜，这是这门生意最早的立足点。

后来 Claude Code、Codex 这些编程 Agent 又把需求推高了。以前用模型是提问一句、回答一次，偶尔充点钱应急完全没有问题。

而自动化工作流和长上下文工作流需要 SOTA 级别的 Agentic 模型大量读文件、调工具、压缩上下文，Token 消耗是连续的，同一个任务走 API，费用可能是订阅会员的 5 倍、10 倍甚至 20 倍。

用不上订阅会员的人很容易被便宜的宣传吸引，也就进了圈套。 **在编程 Agent 的时代，中转站基本成了不少开发者离不开的日常基础设施。**

需求变大，供应的链条也随之复杂，整个中转江湖大致能分为三层：

【1】账号和资源：官方 API Key、企业折扣、账号池和反代技术，甚至海外盗刷的信用卡和接码服务；

【2】中转站的站长：管账号、管路由、管封号之后的补救；

【3】用户和各级代理：从二级一直到四级，个人开发者、企业团队，以及从大站批发额度再转卖的小代理。

最大的特点就是 **模块化** 。 **一个站点被封，账号商、账号池、卡商、技术方案都是现成的，几乎没有迁移成本，换个域名就能重新开张。**

这也是为什么这门生意做起来像「江湖」，不像一家公司。

某种程度上，中转站是 AI 时代最矛盾的一类基础设施。

它一边降低了先进模型的使用门槛，让很多本来用不上 Claude、GPT 和 Coding Agent 的人先用起来；另一边，它又把信任、合规、数据安全和模型真实性全部压进了一个黑箱。

它既像水电煤一样被高频使用，又不像真正的基础设施那样可审计、可追责、可长期依赖。

这也是为什么，中转站不会只是灰产新闻里的边角料。它其实暴露了一个更大的问题：当 AI 能力越来越像生产资料，谁能稳定、便宜、可信地分发这些能力，就会成为新的权力节点。

今天这个节点可能是 OpenRouter，可能是 B.AI，也可能是某个藏在 Telegram 群和微信群里的小站长。

区别只在于，有人把它做成了公司，有人把它做成了江湖。
