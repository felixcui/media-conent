## 摘要

开源 Skill web-html-image 采用“AI 生成网页再导出图片”的方式，让 AI 通过编写 HTML/CSS 精确控制颜色、字号、版式与间距，再由浏览器渲染并导出 PNG，从而实现专业封面等图像制作。该工具体积小、免费且无需 API 付费，安装后可用于公众号封面、PPT 等场景，核心优势是内容可任意准确修改。

接下来一起来看看。

## 一、工具介绍 🛠️

web-html-image 是一个用 **前端渲染出图的开源 Skill** 。其实就是让 AI 用写代码方式去画图，写一段 HTML/CSS，把颜色、字号、版式、间距全部描述清楚，剩下的交给浏览器。渲染完，导出一张真正的 PNG。

跟普通的 AI 直接生成图片区别也在这儿，生图工具拼的是模型能力， **这 Skill 拼的是代码执行得准不准** 。

![](https://mmbiz.qpic.cn/mmbiz_png/L3QFuGxENjf4ibzwD56kpa19V8TLzG79LkqzmibCYV2HOaNpFCATsWysR49hw559Y7rUkKWnK5qTwKn2gDkFfdKHktFC0GFCya7Ds6iaAyFdGU/640?wx_fmt=png&from=appmsg)

这个 Skill 很小，一组 Markdown 说明加两个 Node 脚本，加起来不到 600KB。 **MIT 协议，免费，也不用给 API 付费** 。

### 2\. 它知道每个平台会盖住哪里

下面有一些细节点，还挺智能的：

- 公众号列表页会把封面裁成正方形取中间，所以主标题必须落在水平中段；
- 小红书的底部 18% 会被平台标题栏盖住，落款得往上收；
- X 主页头图左下角 200×200 被头像挡住，右下角还有按钮，别放字；
- 视频缩略图实际展示时只有 210px 宽，标题不够大就直接糊。

这些位置，我全是靠踩坑记住的。它直接写进了规则里。所以我们不用记，关键信息它自己会避开被遮的地方。

## 四、注意点 🌈

简单说完怎么用了，说点实话。

**第一，它做不了照片级的东西。** 真人照片、风景大片、材质质感，都不行。它擅长的是排版驱动的图，比如封面、头像、卡片、Banner、数据图、海报。真需要照片质感，还是得换工具。

**第二，它不适合“随便来一张”这种需求。** 它的确定性全靠我们的描述撑着。图发哪、什么场景、什么风格，这三件事说不清，它就会一直问下去。想零思考出图，直接生图确实更快。

**第三，个别效果要绕一下。** 比如毛玻璃（ `backdrop-filter` ）在页内导出时不会被渲染，得用半透明底加一层模糊装饰替代，或者走脚本出图那条通道。这类限制文档里都列着，知道就行。

这几个注意下。
